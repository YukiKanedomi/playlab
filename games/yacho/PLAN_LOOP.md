# コアループ再設計 計画（統合版）

> 2026-08-14。オーナー指摘「序盤は数手で終わる。敵のそばで3つ揃えるのを数回やって終わりの繰り返し」への計画。
> 一次資料：`assets_src/loop_research_fable.md`（Fable調査）と `assets_src/codex_research_loop.md`（Codex独自調査）。
> 本書が実装の正典。ROGUE.md §6（層構成）と §5（敵）は本書で上書きされる。

## 0. 診断（両者が一致した点）

**「良い一手」の定義が10層すべて同じ**であることが単調さの正体。原因は分解すると：

| 原因 | Fable | Codex | 統合判断 |
|---|---|---|---|
| 目的が全層同じ（殲滅） | 2位 | 2位（25%） | **主因。最優先で直す** |
| 敵が「殴られるのを待つHPブロック」 | 3位 | 3位（20%） | 主因 |
| 判断が敵の四近傍に収束する | ①の一部として指摘 | **1位（30%）** | **主因**。Codexの指摘の方が鋭い |
| 資源（HP）が決断に絡まない | 4位 | 4位（15%） | 直す |
| ペーシング（層が3手で終わる） | ⑤ | 5位（10%） | 直す |

**実測の裏付け**（`_runsim.txt`）：層1は平均3.11手、層2は2.83手でクリアしている。**戦術を提示して回収する時間が存在しない**。さらに層1〜2では `swarm伝播/手` が `build撃破/手` に匹敵し、派手さの源がプレイヤーのビルドではなく敵の自壊規則になっている。

## 1. 意見が割れた点（重要）

**Fable案**：4系統に固定の役割を与える（植物＝回復／鉱物＝攻撃・隣接不要／ギア＝装置／遺物＝通貨）。Dungeon Raid 方式。
**Codex案**：**反対**。「戦闘資源色を重ねると盤面の意味が読めなくなる」。代わりに**フロア目標で「今どの色に価値があるか」を変える**。

**採用＝Codex案。** 理由は3つ。
1. 固定役割は強化システム（植物→胞子→爆発鉱石…の因果）と競合する。同じ駒に2つの意味を持たせることになる
2. 目標駆動なら**層ごとに価値が変わる**ので、変化の総量はむしろ大きい
3. 実装コストが圧倒的に安い（旧30レベル制の `Goal` 機構がそのまま使える）

ただし Fable 案から**1点だけ採る**：「敵の隣で消す」という単調な行動を**直接否定する敵**を入れる（下記 D-2 吸精/採集型）。Codexの診断1位への直接の回答になるため。

## 1.4 【最終決定】資源は「酸素」1本にする（2026-08-14・これが最上位の指示）

議論の到達点。**HPを廃し、最初から酸素を唯一の資源にする。**

### なぜこうなったか（議論の経緯・再検討時に必ず読むこと）
1. 「酸素とHPの2本立ては複雑」→ 酸素を見送り、HPを時計にする案を検討
2. しかし**「敵を倒し切るとHPへの圧力が消え、あとは目標を淡々とこなすだけになる」**という穴が判明
3. 「目標が放置で劣化する」案で補おうとしたが、**劣化は摩擦であって圧力ではない**（失敗に繋がらないので時間をかければ必ず達成できる）と判明
4. 結論：**時間の経過そのものが資源を削らないと、圧力は成立しない**。ならば資源を2本持つ意味がなく、**最初から酸素1本**が最も単純

### 仕様
- **資源は酸素のみ**（HPは廃止）。**1スワップにつき酸素-1**＝残り酸素がそのまま残り手数。読み方が一意で説明不要
- **0でラン終了**（遭難）。失敗条件はこれ1つだけ
- **層クリアで補給**（探窟の補給点）。早く達成するほど残りが次層への貯金になる＝急ぐ動機
- 表示は**既存の「探窟灯の油槽ゲージ」をそのまま酸素計に転用**（ランタンの油＝残り酸素。素材の作り直し不要）。予告チップも既存のものを流用

### 敵の役割（メイドインアビスの世界観に沿わせる）
- **基本は「目標達成を阻害する妨害要素」**。封鎖・甲殻・資源の捕食・盤面の侵食など。直接ダメージは持たない
  - 妨害は酸素を直接奪わないが、**対処に手数を使わせる**＝間接的に酸素を削る。「排除するか、無視して目標へ直行するか」の判断が常に立つ
- **敵殲滅が目標になる層もある**（目標の一種としての戦闘）
- **バリエーションとして、まれに酸素を直接奪う敵**を出す（深界の危険。予告つき）

### 数値の初期案（runsim で較正する）
| 項目 | 初期値 |
|---|---|
| 開始酸素 | 40 |
| 消費 | 1手 = 1 |
| 層クリア補給 | +10（深層ほど微増も検討） |
| 酸素を奪う敵の行動 | -3（予告あり） |
| 想定総手数 | 10層で 85〜100手 |

> 較正の指針：クリア率30〜60%、深層ほど残酸素が細るカーブ。`core/runsim.ts` で計測する。

## 1.5 オーナー決定（2026-08-14・この節が実装の直接の指示）

議論の結果、**酸素（手数時計）は導入しない**。圧力要素を増やすと複雑になるため。
その代わり、指摘された穴——「HPだけを圧力にすると、**敵を倒し切ったあとは目標を淡々とこなすだけ**になる」——を、
**新しい資源を足さずに目標側で解く**：

> **目標そのものに「放置すると悪化する」性質を1行だけ持たせる。**
> - 蔦苔：一定手数ごとに隣へ1マス広がる
> - 匣：一定手数ごとに閉じ直す
> - 植物標本：一定手数ごとに1本枯れて数が減る
>
> 圧力＝「敵（生きている間）」＋「目標の劣化（常時）」。敵を全滅させても時計は止まらない。
> 新しいUI・資源はゼロ。ルールは目標1つにつき1行に収める。

> ⚠️ 以下の表は §1.4 の最終決定より前の中間案。**酸素とHPの行は §1.4 で上書き済み**（酸素1本に統一）。
> 目標・swarm・ボスの行は有効。

### 確定した着手範囲
| 項目 | 決定 |
|---|---|
| ~~酸素（手数時計）~~ | ~~入れない~~ → **§1.4 で採用に変更（唯一の資源）** |
| ~~共有HP~~ | ~~現行20のまま~~ → **§1.4 で廃止** |
| 最初に入れる目標 | **植物標本12 / 蔦苔6浄化 / 遺物救出（陶片3） ＋ 殲滅** の4種 |
| 光胞子の搬送 | 第2弾へ（浮上と落下の相互作用が読みにくい） |
| swarm | **提案どおり変更**：HP2・1ラン12〜18体・伝播は「4個以上マッチ／爆発／特殊駒」で倒したときだけ |
| ボス | **工夫は欲しいが最初はシンプルめ**（今後増える前提）。→ 2段階案：①封印匣を開いて核を露出 ②本体HPを削る。下2行占有は1行へ縮小 |

## 2. 実装計画（4段階）

### 第1段階：目標と時計【最優先・最も安い】
現行エンジンの `Goal` と `movesLeft` は**捨てるべき遺物ではなく、今もっとも安くループを直せる資産**。ローグ用に薄く包んで復活させる。

- **フロア目標**を導入し、殲滅は「目標の一種」に降格する。目標達成時に残敵がいてもクリア
- 初回10層で使う目標（すべて既存機構で実装可）：
  | 目標 | プレイヤーの行動が変わる点 |
  |---|---|
  | 植物標本12 | 敵の隣より植物のまとまりを狙う |
  | 幼体を倒す | 基本戦闘（既存） |
  | 蔦苔6マス浄化 | 角・辺・分散地点を順に狙う |
  | 光胞子2個を上端へ搬送 | 胞子の上を空ける経路計画 |
  | 遺物救出：陶片3 | 匣を開けて中身を回収する二段手順 |
  | 機構再始動：ギア4回起動 | 敵から離れたギアにも価値が出る |
- **酸素（ソフト手数時計）**：1スワップで-1。0で即敗北ではなく「圧壊」＝HP-3・盤面2マス封鎖・酸素+4で続行
- **共有HPは20→12**。3/6/9層の自動回復は撤廃し、層5後に「修理+3 か 強化を取る」の**選択**へ集約（HPが初めて意思決定の通貨になる）

### 第2段階：敵の作り直し
- **swarm を縮小**：現行61体→1ラン12〜18体。**HP2**にし、**伝播は「4個以上マッチ・爆発・特殊駒で倒したときだけ」**に限定。自動ドミノはプレイヤーの仕事を奪っている
- **裂坑掘り**（新）：2手ごとに敵から最も遠い2x2を予告。その領域内を消せば中断、無視すると封鎖。**盤面全域を見る理由**を作る。現行の穴潜みのランダム封鎖を置換
- **採集蟲**（新・Fable案由来）：2手後に胞子/爆発鉱石/充填ギアを食べてHP回復。**その資源の隣でマッチすれば追い払える**＝敵の隣ではない場所を触らせる
- 直接HPを削る攻撃は**エリートとボスだけ**に。通常敵は封鎖・侵食・資源捕食で「一手の価値」を変える

### 第3段階：層構成の差し替え（10層）
| 層 | 目的 | 敵 | 期待手数 | 学ぶこと |
|---:|---|---|---:|---|
| 1 | 植物標本12 | なし | 5〜6 | 殲滅だけのゲームではない／酸素を安全に学ぶ |
| 2 | 幼体4体撃破 | 幼体4 | 6〜7 | 各個撃破か、集めて大技で一掃か |
| 3 | 蔦苔6浄化 | 幼体2 | 7〜8 | 敵の隣より目標マスを優先する空間読み |
| 4 | 光胞子2搬送 | 幼体3 | 8〜9 | 落下と逆方向の経路計画 |
| 5 | 裂坑掘り撃破 | 裂坑掘り1 | 8〜9 | 新敵を既知目標で単独学習／**修理か強化かの選択** |
| 6 | 遺物救出：陶片3 | 裂坑掘り1 | 9〜10 | 既知の敵＋新目標の組合せ |
| 7 | 機構再始動：ギア4 | 幼体3 | 8〜10 | 敵の近くにないギアも価値を持つ |
| 8 | 晶殻獣撃破 | 晶殻獣1 | 9〜11 | 小刻みに殴らず、大単発を準備する |
| 9 | 反響クラゲ撃破 | 反響クラゲ1 | 10〜12 | 逆に、同じ手に小ヒットを何本重ねるか |
| 10 | ボス3段階：①封印匣4を開く ②ギア4回起動 ③本体HP20 | ボス | 12〜15 | 既習の再試験→最後だけビルドの試射 |

**合計83〜90手**（現行の30〜50手から倍増）。新要素は必ず単独で提示してから組み合わせる。
ボスは**下2行占有→1行**に縮小（盤面を25%狭めるのは攻撃地点を下辺に固定するだけ）。

### 第4段階：仕上げ
- 晶殻獣（大単発を要求）と反響クラゲ（多段を要求）のダメージ規則
- 深層異常（Balatroのボスブラインド型・生存中だけ盤面ルールを変える）
- ドラフト回数を9→7に（層1と層10の後を除く）。薄く10個より、試す時間のある7個

## 3. 削るもの（Codex[G]より採用）

1. **swarm 61体と自動伝播**（プレイヤーの仕事を奪い、弱い手を派手に見せる）
2. **全層殲滅**（層2・5・8・9の敵役割テストに限定）
3. **`moves:9999`＋不可能な色ゴールのダミー**（旧Goalを正式に使う）
4. **すべての敵が定期的にHPを削る設計**（予告の強いエリート／ボスだけに）
5. **穴潜みのランダム封鎖**（読んで防げない妨害は戦術でなく税）
6. **胞子獣の「毒駒を消すとHP-1」**（盤面整理という正しい行動に罰を付けている）
7. **3/6/9層の自動HP回復**（層5の一度の選択へ集約）
8. **菌糸層/結晶洞のランダム増殖**（目標に接続できるまで一旦外す）

## 4. 最小の有効改修

新敵6種を先に作る必要はない。**①旧Goalをローグへ戻す ②酸素時計 ③swarm縮小 ④10層を上表へ差し替え** の4点だけで、「どこを、なぜ消すか」が層ごとに変わる。そこへ予告型の裂坑掘りを1体足せば、現行エンジンのままコアループが別物になる。

yacho / mockups / v6

UI部品キット ── そろえて、しるす。

構造はオーナー提供の参照（owner_ui_ref.jpg）から、画材は採用コンセプト画から取っている。 見出し帯・統一カード・一覧行・平坦で十分な地・明確なボタンという「アプリの骨格」をそのまま借り、 その表面だけを真鍮・古紙・インク・水彩・革へ置き換えた。絵はUIを兼ねない。 情景は情景の枠の中にとどまり、文字は必ず自分の不透明な札の上に載る。 文中の名前（知見・原生種・課目・祝福）はすべて src/core に実在するものだけを使っている。

00

この部品が守る5つの規則

rules

文字が安っぽくならないための規則

① 数字も文章も、必ず自分の不透明な札の上に載る。賑やかな絵の上に本文を直接置かない。

② 影と縁取りで可読性を作らない。text-shadow・stroke はこのキットに1件も無い（§10で実測）。チープさの正体はそれ自体である。

③ 紙目は全面に残すが、文字が載る中央だけ顔料ムラを抜く。素材感と可読性を両立させ、どちらも諦めない。

④ 書体は役割ごとに1つ。見出し＝明朝600／本文＝ゴシック500／数字＝等幅ライニングのサン600。数字は全画面で同じ1書体。

⑤ 部品は中身の長さで伸びる。「残灯 6」でも「残灯 107」でも、「胞子弾」でも「早足の測量 ── 盤の四隅が欠ける」でも壊れない（§10）。

参照から取った構造／絵から取った素材

構造（参照）：panel の上端に必ず高コントラストの見出し帯。同型のカードを反復。一覧は左にアイコン鉄道、右に数値。ボタンは側面を持つ板。キャラと絵は枠に差し込むだけで、文字の下に潜らせない。

素材（コンセプト画）：真鍮の環と留め具、古紙の身、インク一色（#2F2922）の輪郭、水彩の面、緑青の凹部、革の帯。灯は真鍮の口金を持つガラス管の中の冷たい発光液。

この2つを混ぜない。v5の失敗は絵にUIを兼ねさせたこと。v4の失敗は素材を持たなかったこと。

01

色域

palette

ART_GRAMMAR §2.1 の色域そのまま。明部は彩度15〜22%の古紙、暗部は彩度20〜35%を保ち luma 22 を割らない。純黒・純白・彩度50%超の明部は使わない。朱 #C4553E は印と面にのみ使い、紙の上の朱の文字は一段暗い #8E3A29 を使う（コントラストのため）。

04

ボタン

button

押せて見えることの根拠は「側面」。板の下に 3px の暗い側面があり、押下すると側面が消えて板が沈む。上辺の温白ハイライトは全幅に通さず途切れさせる（連続ベベル＝CG金属の署名を避ける）。
明るい真鍮の板には暗いインクの文字、暗い木・緑石の板には象牙の文字。これは好みではなく実測の結果で、当初は真鍮に象牙を載せていたが §12 の実測で 2.48:1 しか出ず（合格線 4.5:1）、地の側を選び直した。地の明度が文字の明度を決めるという不変条件そのままである。無効の板も無効のまま 4.5:1 と Δluma 120 を割らない。

実測 ── 文字は安っぽくないか

measured

このページに実際に描画されている文字を JavaScript で走査し、算出済みの文字色とその文字が実際に載っている不透明な地の色を取り出して、 WCAG コントラスト比と ART_GRAMMAR §6.1 の Δluma を計算している。表の数値は書いた値ではなく描画された値である。 合格線は 本文 4.5:1 以上（WCAG AA）かつ Δluma 120 以上（一次資料の最小値116を安全側に丸めた値）。

部品／役割文字色地の色字送りWCAGΔluma影・縁取り判定
紙目の実測 ── このページを描画した PNG を Pillow で測った値

ART_GRAMMAR §3.2 は、UI が「別の画材で描かれた異物」に見える原因を高周波エネルギー HF ＝ mean|L − Gaussian(σ=2)| で定式化している。 一次資料の UI プラーク内部は HF 20.97、実機の hud_kit_v5 は HF 3.52。合格線は HF ≧ 12。

本キットのパネル本体（文字のない帯）を実測すると HF 12.1 / 13.2、平均 luma 207 / 211（羊皮紙の規定域 200〜225 の内側）。 UI は絵と同じ紙の上に描かれている。

そのうえで可読性が壊れていないことも測った。紙目で地は局所的に沈むが、σ=2 で均した実効的な地の下位1%は luma 188、 そこに本文インク #3A2E20 が載ったときのコントラストは 7.1:1。最悪の一点（luma 152）でも 5.2:1 で、合格線 4.5:1 を割らない。 紙目を入れても文字は安っぽくならない──ただしそれは、紙目を文字の下に敷き、影と縁取りを一切使わなかった場合に限る。

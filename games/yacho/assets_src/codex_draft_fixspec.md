## 2. 修正仕様

### 標本票の描画方式

**任意アスペクトへの引き伸ばしは廃止します。**

実装は次で固定します。

1. 紙本体を装飾なしの9-sliceへ分離する。1024×512基準で固定縁は左右72px・上下64px。
2. 葉、穴、クリップ、紐、円形台紙、破れ紙片は別スプライトに分離する。
3. 装飾は `cardW / 1024` の等倍スケールのみ。上／下／左右の対応辺へアンカー固定し、縦だけ伸ばさない。
4. 紙本体だけを計算済みカード高へ9-sliceする。
5. 分離完了までの暫定実装は、元画像を**2:1固定**でのみ表示する。縦横別倍率による出荷は禁止。

カード幅と高さは以下です。

```ts
cardW = Math.min(viewportW - 32, 400)
naturalH = cardW / 2
minH = Math.max(176, naturalH)
cardH = Math.max(minH, measuredContentH + topInset + bottomInset)
```

3枚が候補領域へ収まらなければ、カードを縮めず候補領域を縦スクロールにします。

### 安全域

値は元1024×512素材上の装飾実測に基づく割合です。**文字・印・呼応・帯の全バウンディングボックス**に適用します。

| 票種 | 基本安全域 | 追加規則 |
|---|---|---|
| plant | `x: 9–76% / y: 15–80%` | 右上の葉を避けるため単一矩形では76%を上限とする。本文が素材高60%より下だけにある場合に限り右端90%まで拡張可。 |
| instrument | `x: 13–93% / y: 14–87%` | 左クリップを全行で避ける。本文を10%位置から開始してはならない。 |
| relic | `x: 14–77% / y: 14–84%` | 左の紐・穴、右の円形台紙・破れ紙片を完全除外する。 |
| fallback | `x: 8–92% / y: 12–88%` | 装飾のない生成紙だけに使用可。 |

`推`印は本文安全域を消費させず、専用の装飾領域へ置きます。本文幅を確保できない場合は非表示にします。

### 折返し・行数・カード高の決定順

1. `cardW`と票種別安全域を確定。
2. 本番フォントのロード完了後、見出し・本文・呼応・おまけを実測。
3. 見出しは最大2行、本文は最大4行、呼応は1行、おまけは1行。
4. 余白を標準8pxから最小4pxまで削減。
5. `推`印を省略。
6. 呼応アイコンを最大3個から1個＋`+N`へ畳む。
7. おまけ文を1行省略記号付きへ短縮し、全文は野帳で確認可能にする。
8. それでも不足する場合はカード高を増やし、3枚の領域をスクロール化。
9. フォント縮小は最後。本文は13px未満、補助文は11px未満にしない。収まらなければ縮小せずスクロールする。

本文・効果名の省略は禁止です。4行を超えるデータはカード用短縮文を別途用意し、全文を野帳へ掲載します。

### 呼応行・おまけ帯

通常フローとして次の順に積み上げます。

```text
見出し
本文
6px
呼応行（存在時のみ）
6px
おまけ帯（存在時のみ）
下余白
```

- `rowY + requiredHeight <= safeBottom` を満たしてから描画する。
- 呼応は高さ `max(20px, iconSize + 4px)`、最大3アイコン。狭い場合は1アイコン＋`+N`、さらに狭ければ `呼応 +N`。
- おまけ帯は最小28px・1行固定。溢れる文は省略記号とし、帯自体を紙外へ移動しない。
- 両方が入らない場合は、まず `推`印を消し、次に補助表示を畳み、それでも不足ならカード高を増やす。
- `bandY`の `Math.max(...)`配置は廃止する。
- 最終防衛としてカード内にマスクを設け、デバッグビルドでは安全域超過をassertで失敗させる。

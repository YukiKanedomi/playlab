# コアループ再設計リサーチ（Fable版）

> 2026-08-14。オーナー指摘「序盤は数手で終わる。敵のそばで3つ揃えるのを数回やって終わりの繰り返し」への回答。
> Codex の独自調査は `codex_research_loop.md`。本書と突き合わせて最終計画を作る。

## 1. 何が退屈なのかの分解

現状を分解すると、**単調さの原因は5つ**あり、影響の大きい順に並べるとこうなる。

### ① 4系統がすべて同じ仕事をしている（最大の原因）
植物・鉱物・ギア・遺物のどれを消しても、盤面上で起きることは同じ＝**隣接する敵にダメージ**。強化を取れば副次効果は変わるが、**「今どの色を消すべきか」という毎手の判断が存在しない**。プレイヤーの思考は「敵の隣で成立する手を探す」に一本化される。

比較：**Dungeon Raid**（マッチ3ローグライクの原点）では、タイルが敵・金貨・回復薬・盾・経験値に分かれ、**どれを消すかがそのまま「今なにが足りないか」の意思決定**になる。HPが減れば回復薬を、防御を上げたければ盾を優先する。盤面は同じでも、状況ごとに正解の手が変わる。

### ② 層の目的が10層すべて同じ
全層が「敵を全滅させる」。**Royal Match** は層ごとに目的（ゼリー除去・箱破壊・アイテム収集・複数同時目標）を変え、しかも複数目的を同時に課すことで「競合する目標のどちらを優先するか」を作っている。うちにはその競合がない。

### ③ 敵が「殴られるのを待つHPブロック」でしかない
**Slay the Spire** の敵は、プレイヤーの通常戦術を**禁じる**ことで戦闘を差別化している。攻撃的な敵は防御を強制し、装甲持ちはスケーリングを要求し、デバッファーは対抗手段を要求する。うちの敵は「隣で消す」以外の解を要求しない。特にサンドバッグ（HP1・撃破で伝播）は、**弱いビルドでも派手に見える**代わりに、判断を一切要求しない。

### ④ HPが唯一の資源で、しかも判断に絡まない
夜間のバランス調整で事故死は消えたが、その結果**HPが「たまに減る背景数値」**になった。使い道も回復手段もないため、「HPを削ってでも攻める」というトレードオフが発生しない。

### ⑤ 盤面が悪化しない＝空間的な緊張がない
**Shovel Knight Pocket Dungeon** は 8×8 の盤が上から埋まり、**1手ごとに盤が下がる**。放置すると詰む。うちの盤面は放置しても悪化しないので、「早く処理しないとまずい」という圧が働かない。

## 2. 参照ゲームから移植できるもの／できないもの

| 出典 | 仕組み | うちへの移植 |
|---|---|---|
| **Dungeon Raid** | タイル種別＝資源種別。消す対象の選択がそのまま資源管理 | **移植可・最優先**。4系統に別々の役割を割り当てるだけで、エンジン改修は小さい |
| **Royal Match** | 層ごとに目的が変わる／複数目的の競合 | **移植可**。目的判定は既にゴール機構がある（旧30レベル制の遺産が使える） |
| **Slay the Spire** | 敵が通常戦術を禁じる。幕ごとに要求が変わる（Act2=分裂・召喚、Act3=大HP） | **移植可**。敵の行動は実装済みなので、行動の種類を増やす |
| **Balatro** | ボスブラインド＝**必ず通る強制的な制約**。ランごとにランダム。一本槍のビルドを罰する | **移植可**。ROGUE.md のバックログにある「呪い・深層異常」がまさにこれ。1層に1つ制約を出す |
| **Pocket Dungeon** | 盤が上から埋まる。1手ごとに悪化 | **一部移植可**。全面採用すると別ゲームになるので、「特定の層／敵だけ盤を侵食する」形に限定 |
| **Puzzle Quest** | 色＝マナ。色ごとに使える魔法が違う。敵に属性と固有スキル | **概念のみ移植**。マナ蓄積→発動の二段階はテンポを損なうため、うちの「即時発火」を維持 |

**移植しないもの**：Puzzle Questのターン制マナ蓄積（テンポが落ちる）、Pocket Dungeonの全面ボード侵食（カジュアルな入口を壊す）、Dungeon Raidの装備・スキルツリー（恒久成長なしの方針に反する）。

## 3. 提案する変更（効果の大きい順）

### A. 4系統に別々の役割を与える【最優先・エンジン改修は小】
| 系統 | 役割 | 消したときに起きること |
|---|---|---|
| **植物** | 回復 | 探窟隊HPを回復（**唯一の回復手段**） |
| **鉱物** | 攻撃 | 敵にダメージ（隣接不要。最も近い敵へ飛ぶ） |
| **ギア** | 装置 | 特殊駒ゲージを溜める（既存のギア起動を流用） |
| **遺物** | 報酬 | 遺物の欠片＝ドラフトの**リロール**や追加選択肢に使う通貨 |

これだけで毎手の判断が「敵の隣で消せる手を探す」から「**HPが危ないから植物／固い敵がいるから鉱物／そろそろ特殊駒が欲しいからギア**」に変わる。Dungeon Raid の核心をそのまま持ち込む形。

**重要**：鉱物を「隣接不要」にすることで、**「敵の隣で消す」という単調な行動そのものを廃止**できる。

### B. 層の目的を多様化する【Royal Match方式】
- **殲滅**（既存）
- **採掘**：岩盤をN個破壊する。敵は妨害役に降格
- **脱出**：N手以内に盤面下端まで通路を開ける（落下パズル）
- **救助**：閉じ込められた探窟家を下端まで落とす（既存の重力と障害物を流用）
- **護送**：壊れやすい遺物を下端まで運ぶ（守りながら消す）
- **ボス**

複数目的の同時提示（例：救助しながら敵の攻撃を耐える）で競合を作る。

### C. 敵アーキタイプを「戦術を禁じる」設計に【StS方式】
| 敵 | 禁じるもの／要求するもの |
|---|---|
| **甲殻獣**（改） | 多段ヒット無効。**1回で3以上のダメージ**でないと通らない＝鉱物を溜めさせる |
| **吸精体** | **隣接マッチを吸って回復**する。近くで消すと強くなる＝離れた場所で消させる（現状の単調行動を直接否定） |
| **増殖菌** | 3ターンごとに分裂。放置＝処理不能に |
| **封印獣** | 生存中は**1系統をロック**（例：植物が消せない）＝Balatroのボスブラインドの常設版 |

### D. 深層異常＝層ごとの強制制約【Balatro方式】
深度5以降、層ごとにランダムな制約を1つ提示（開始前に予告）。例：`鉱物は2回消さないと消えない` / `3手ごとに盤面下端が1行せり上がる` / `同じ系統を連続で消せない`。**一本槍のビルドを罰し、毎ランの判断を変える**のが狙い。

### E. HPの再設計
Aの導入で**植物＝回復**になるため、HPが「毎手の判断に絡む資源」に変わる。その上で：
- 敵の攻撃を**予告どおり必ず当てる**（現在は事故的にまとめて来る）
- 最大HPは20のまま、**回復は植物マッチのみ**（節目の自動回復は撤廃）
- 深層では「回復量が減る」異常を出して、後半の緊張を作る

## 4. 実装コストの見立て

| 提案 | コスト | 依存 |
|---|---|---|
| A 系統の役割分け | **小**（board.ts のマッチ解決に分岐を足すだけ） | なし |
| C 敵アーキタイプ | **中**（敵の行動は実装済み。判定の追加） | なし |
| D 深層異常 | **中**（環境フラグの拡張） | なし |
| B 目的の多様化 | **大**（勝利条件・UI・レベル定義） | 旧ゴール機構の再利用で軽減可 |
| E HP再設計 | **小**（Aに付随） | A |

**推奨順序：A → C → D → B**。Aだけで「毎手の判断」が生まれるため、まずAを入れて実機で確かめるのが最短。

# 『yacho（そろえて、しるす。）』次フェーズ戦略 v2

> 結論：次フェーズの目的は「要素数を増やす」ことではなく、**深界を観察し、知識を持ち帰るゲームへ全要素を同じ文法で束ねること**である。現在のコアループは、酸素1本・目標駆動・平均91.6手・10層クリア率39.2%まで成立している。ここへ30面、祝福、新敵を同時に足すと、成立した較正を壊し、薄い内容を三倍に延ばす。先に語彙・敵の生態・HUDの読み順を一本化し、その型で量産する。

## 前提判断

- `PLAN_LOOP.md §1.4` と `SPEC_OXYGEN.md` を最上位とし、**資源は酸素だけ**にする。祝福用通貨、マップ移動力、HP、満腹度は足さない。
- 現行10層は1層8.7〜11.6手、全体91.6手に較正済みである。「1層が短い」のではなく、**各層の前後が薄く、敵が生物として記憶に残らない**ことが「あっさり」の主因である。
- 現行の強化20種は挙動変化と因果連鎖がすでに強い。一方、見出しが「強化」、関係表示が「接続」、説明面が「野帳」なので、裏側の面白さが開発用語のまま見えている。
- 添付実機画面は装飾量が不足しているのではない。むしろ枠・札・数字が同じ強さで競合している。追加装飾より**情報の降格と数値書体の分業**が先である。
- 参照作から借りるのは、未知を「固有名＋観察記録＋危険な行動」で理解させる仕組みであり、固有名詞・意匠・生物案は一切借りない。

## [A] 命名体系の設計

### 1. register：誰が誰に向けて書いた言葉か

画面を「古い本っぽいUI」にするだけでは語彙は締まらない。本作の全テキストを、次の一人称を省いた記録として統一する。

> **帰還した先遣探窟家が、次に降りる無名の後続者へ残した採録。** 研究論文ではなく、命を守るための実地記録である。見出しは短く、本文は「観察された事実 → 対処」の順に書く。詩的な語は固有名にだけ許し、機能説明は平明にする。

優れた参照作の命名は、難しい漢字を使うから良いのではない。機構は次の四点である。

1. **先に像が立つ固有名**：形・生息場所・不気味な性質のうち二つを短い名に圧縮する。
2. **説明しすぎない余白**：名前は生物の全能力を言わない。能力は観察記録で明かす。
3. **語り手の制約**：「ゲームシステムが告知する」のではなく、「生還者が確認できた範囲を書く」。未知が嘘ではなく未観測になる。
4. **危険と美しさの同居**：脅威を「敵」「モンスター」とだけ呼ばず、生態系の一員として扱う。倒す以外の判断が自然になる。

本作では、既存の「探窟家・深度・胞子・遺物・酸素・匣」は維持する。これらは短く、物質感があり、上のregisterに合う。「強化・接続・ターゲット」は開発語なので、採録者の語彙へ置換する。

### 2. 正式語彙表

| 現在／開発語 | 正式表示 | 用途と文例 |
|---|---|---|
| 強化 | **知見** | 通常能力の総称。「深度1 踏破――知見をひとつ採る」。能力は力を注入されたのではなく、深界の扱い方を学んだとする |
| 強化を選ぶ／ドラフト | **採録** | 行為名。「三つの観察から一つを採録する」。ボタンは「この知見を採る」 |
| 接続 | **呼応** | 能力間の因果。「胞子を生む知見と呼応」。数字だけなら「呼応 1」、詳細では必ず `Aが胞子を生む → Bが使う` と書く |
| 野帳 | **採録帖** | 共通情報面。「野帳」は一般名すぎ、ボタン名として目的が弱い。採録帖には知見・原生種・用語・発見記録を収める |
| 敵 | **原生種** | UIと記録上の総称。コード上のenemyは変えなくてよい。「掃討」は殲滅目標にだけ残す |
| 敵インテント | **兆候** | 「あと2手：掘削」ではなく、敵のそばに亀裂アイコンと `2`。採録帖では「崩落の兆候」と記す |
| ターゲット／goal | **課目** | 層で果たす作業。「本層の課目」「植物標本 あと41」。軍事命令より採集・調査の語感を優先する |
| 祝福／大型強化 | **深層印** | ボス級の規則変更。深界から授けられる善意ではなく、潜った者に残った不可逆の徴。通常の知見と語源も見た目も分ける |

マップは **深度図**、1ランは **一度の探窟** と呼ぶ。「ビルド」はプレイヤー向けには使わず、結果画面では「今回の採録」「最も働いた知見」とする。

### 3. 文体ルール

- 固有名は4〜6文字を基本にし、難読語には初出だけ振り仮名を付ける。
- 課目は名詞＋残数にする：`植物標本　あと41`、`原生種　あと1`。`9/50` は作業量の理解に逆算を強いるので廃止する。
- 兆候は動作名＋残り手：敵の上に `崩落 2`。酸素を直接奪う場合だけ `酸素−3 / 1手` を朱で出す。
- 知見カードは「観察名」「起きること」「採録時のおまけ」の三段。`条件／効果／獲得ボーナス／接続`という開発データの露出はやめる。
- 「深界」「深層」を万能接頭辞にしない。深層印と深度図に限定し、語の価値を薄めない。

## [B] 原生生物の設計論

### 1. 魅力が生まれる四つの機構

1. **生態的な必然性**：行動が攻撃パターンではなく、捕食・擬態・繁殖・縄張り・採餌の結果になっている。見た目から行動を予測できる。
2. **危険度の等級**：HPの大きさではなく、「見落としたときに探窟がどれほど破綻するか」を示す。遭遇前の経路選択に効く。
3. **観察記録としての提示**：初遭遇では名前と一つの兆候だけ。遭遇後に食性、対処、未観測欄が採録帖へ追記される。説明画面を開くこと自体が収集報酬になる。
4. **行動を禁じる形**：単に手数を増やすのではなく、「特殊駒を温存するな」「角だけを見るな」「小マッチを繰り返すな」など、普段の最適行動を一時的に禁じる。ただし植物無効のようにビルド全体を否定しない。

危険度は次の四段階に固定する。

| 等級 | 意味 | UI |
|---|---|---|
| **観察級** | 放置しても即死しない。基本行動を教える | 灰青の一点印 |
| **警戒級** | 数手放置すると課目または盤面が崩れる | 琥珀の二点印 |
| **退避級** | 酸素や盤面の広域へ直接影響する | 朱の三点印 |
| **災害級** | 幕ボス／特殊ボス。盤面規則そのものを変える | 黒金の環印 |

### 2. 現状診断

現行6種は機能差自体はある。小型群れの伝播、甲殻、捕食印、2×2崩落、酸素強奪、二段階ボスはゲームとして正しい。足りないのは次である。

- **機能名がそのまま生物名**で、どこに棲み、何を食べ、なぜその行動をするかが無い。
- 小型群れ以外は単体のHPブロックに見え、シルエットと兆候が結び付いていない。
- 息喰みの同心円などGraphics描画は、危険記号としては読めるが生物として愛着が生まれない。
- 盤面上のアイコン、中央のキャラクター、採録帖の記述が別々で、遭遇が「発見」になっていない。
- 静止しており、呼吸・触角・採餌姿勢・兆候前の身構えがない。これはJUICEの未実装項目と一致する。
- 危険度が無いため、マップで敵を知っても経路判断にならない。

### 3. 具体案：最初の12層までに使える8種

| 原生種 | 見た目の要点 | 盤面での行動 | プレイヤーに強いること | 危険度 | 初出深度 | 実装 |
|---|---|---|---|---|---:|---|
| **環胞虫（かんぽうちゅう）** | 胞子嚢を輪状に背負う指先大の群体。隣同士で菌糸が光る | 現行swarm。大きな一撃で倒すと隣へ伝播 | 3消し連打をやめ、4消し・特殊駒の射線を作る | 観察級 | 2 | **現行挙動の改名＋アートだけ** |

初期量産では上表の最初の5種だけを完成させる。後半3種を同時実装しない。既存挙動でも、シルエット、idle、兆候、観察文が揃えば新敵一種ぶん以上の価値が出る。

### 4. 原生種一体の納品単位

新種は「盤面アイコン1枚」で完成扱いにしない。以下を一組で作る。

1. 全身の生態スケッチ1枚。
2. 盤上の正面／兆候／被弾の3状態。idleは呼吸＋一部器官のループだけ。
3. 生息域、食性、兆候、対処、未観測欄を持つ採録帖1ページ。
4. 初遭遇時の1.2秒の名前札。「敵出現」ではなく `未採録の原生種` → 名称。
5. 深度図の遭遇シルエットと危険度印。

これを満たさない敵は種類数に数えない。

## [C] 30層構成と深層印

### 1. 30面直列は採用しない

現在の平均は9.16手／層である。30層を同じ密度で直列化すると約275手、難化を含めれば約300手になる。オーナー試算の40〜60分は妥当で、**モバイルWebの標準ランとしては長すぎる**。問題は中断保存の有無だけではない。途中でビルドが完成した後も20面近く同じ因果を見るため、強化の発見が作業へ変わる。

結論は次の形にする。

- 世界には**深度1〜30の30面**を用意する。
- 1幕は深度10ぶんだが、分岐降下路により通常面は4面だけ通る。深度10／20／30の主を必ず通る。
- 3幕で `通常4＋幕主1` ×3＝15面、その後に特殊ラスボス1面。**1ラン実プレイは16面、約145〜170手、20〜30分**を目標にする。
- 通らなかった層は次ランの別経路として残る。30面という制作量が、そのままリプレイ性になる。
- 幕主後は自動保存し、「ここで帰還」を選べる。帰還は敗北でなく、その深度までの採録を確定する。続行時は同じランを後で再開できる。

30面すべてを一度に踏破する長時間モードは、通常ランの継続率が確認できてから解放する。最初から主モードにしない。

### 2. 三幕＋特殊ラスボス

| 幕 | 深度 | 主題／要求技術 | 原生種の役割 | 課目の種類 | 幕主 |
|---|---:|---|---|---|---|
| **第一幕：光の届く縁** | 1〜10 | 4消し、目標マス優先、兆候の読み方。酸素を貯める基礎 | 観察級中心。群体、甲殻、予告封鎖を単独で教える | 植物標本、蔦苔、掃討、陶片 | 匣を剥がすたび盤面が広がる。現行ボスを磨く |
| **第二幕：反転する遺構** | 11〜20 | 二つの課目の優先順位、価値の高い駒の保護、ルート選択 | 警戒級中心。課目を戻す、色分布を乱す、既知種の組合せ | 二課目、光胞子搬送、指定地点での起動 | 盤面の左右または重力方向を周期で変える。**新サブシステム**なので幕2完成時に実装 |
| **第三幕：脈動する底** | 21〜30 | 完成ビルドを一手へ集約し、退避級を先に落とす | 退避級＋既知種の変異。酸素強奪は全編成に一体まで | 三段匣、移動目標、掃討＋採集の複合 | 兆候に応じて盤面の安全域が変わる。強化無効は行わない |
| **底の外：特殊ラスボス** | 30後 | 三つの深層印と完成ビルドの総試験 | 生物というより地形規模の現象 | 三幕で多く採った課目二種を再構成 | 過去の幕主の技を順番に再利用せず、**プレイヤーの最頻行動に反応して盤面形状を変える** |

特殊ラスボスは「さらにHPが多い敵」にしない。酸素を直接奪うだけでもない。盤面8×8の使用可能域を `8×8 → 二つの4×6領域 → 中央十字` と変え、最後に全域を開放する。既存の封鎖・解放セルを拡張して作り、新しい戦闘資源は足さない。

### 3. 深層印の設計

通常の知見と深層印が同じ土俵に見えたら失敗である。差は強さの数値ではなく、作用する階層で作る。

| | 知見 | 深層印 |
|---|---|---|
| 作用 | マッチ、胞子、ギアなど局所イベントへ反応 | 酸素経済、地図情報、層開始、課目構造というラン規則を変える |
| 数 | 1ラン8〜12個 | **最大3個** |
| 入手 | 通常層後の3択 | 開始時1個＋深度10・20の幕主後に各1個。深度30後は選ばない |
| 表示 | 下部の小メダル列、発火時に光る | 画面左縁の大きな縦印。常時最大3枚。毎マッチ発光させない |
| 重複 | 同系統を重ねて因果を作る | 同名重複なし。欠点を含む探窟方針を決める |
| 文 | `植物を3つ消すと胞子が2つ生まれる` | `未知の分岐を一つ先まで読める。ただし補給所が一つ減る` |

開始時の深層印は「最初から強い能力」ではなく、**今回の探窟で何を優先するかを決める契約**にする。

| 深層印案 | 規則変更 | 決めるプレイ |
|---|---|---|
| **遠見の薄膜** | 深度図の未知ノードを一段先まで公開。ただし各幕の最初の補給+7を+5にする | 情報で安全を取るか、酸素余裕を取るか |
| **菌環の肺** | 各層で最初に胞子を消費したときだけ酸素+1。課目クリア補給は常に−1 | 胞子を軸に小さく回収する探窟 |
| **欠けた方位環** | 各幕で一度だけ、選択した分岐を引き返せる。引き返し時に酸素−2 | 地図と未知を攻める探窟 |
| **空洞の反響** | 各層で最初の特殊駒効果だけ二度起きる。その層の開始盤面に匣が2個増える | 一撃構築と障害物処理 |
| **標本守りの膜** | 二課目層で片方を達成すると、もう片方が2進む。単一課目層では効果なし | 難しい複合層を選ぶ探窟 |
| **底風の痕** | 酸素8以下では4消し以上の敵ダメージが+1。酸素12以上では無効 | 低酸素を攻めに変える危険な探窟 |

参照するレリック機構の要点は、常時バフの山ではない。**取得した瞬間から、それまで無価値だった選択肢の価値を変えること**、強い代わりにルートやデッキへ歪みを作ること、取得履歴がそのランの物語になることである。本作ではカード戦闘へ翻訳せず、酸素・課目・深度図・盤面形状の四領域だけを変える。

「呪い」は別アイテムとして増やさない。深層印の一部に明示された代償を持たせ、選択画面で利点と代償を同じ大きさで示す。隠しデメリットは禁止する。

## [D] 層クリア後のリザルト

### 1. 時間予算

層間演出には二種類ある。部屋制ローグライトは通常部屋の退出まで**約1.5〜3秒**、マッチ3の勝利演出は盤面の残処理を含め**約4〜7秒**、報酬選択を伴うデッキ構築ローグライトは判断込みで**約5〜15秒**を使う。本作は1層が約9〜11手なので、毎回5秒止めると現行10層だけで約50秒、16面構成なら80秒以上の待ちになる。

通常層は**1.8秒・入力待ちなし**に固定する。

1. `0.00〜0.35秒`：最後の収集物が課目へ飛び、盤面が一段暗くなる。
2. `0.25〜0.95秒`：細い採録帯が下から出る。`深度6 踏破`。
3. `0.55〜1.45秒`：酸素 `+7` がゲージへ入り、同時に `9手` と最多発火知見だけを出す。
4. `1.45〜1.80秒`：採録帯が上へ抜け、次の深度図または採録選択へつなぐ。

通常層では専用全画面を出さない。現在のドラフト画面へ入る前の薄いオーバーレイにする。幕主後だけ**4〜7秒の全画面採録**を使い、深層印の3択へ接続する。

### 2. 見せる情報

- `酸素 +7 → 残り24`：補給量と結果の両方。酸素1本という最上位方針を毎層再確認させる。
- `この層 9手`：良し悪しの星評価は付けない。前回自己記録がある場合だけ小さく `最短8手`。
- `最も働いた知見：機械庭園 4回`：0回の知見を責めない。最多1件のみ。
- 初見の原生種がいた場合だけ `採録帖に追記` を一行出す。内容は次の深度図で任意に読む。

### 3. 見せない情報

- 全知見の発火一覧、総破壊数、平均連鎖、ダメージ内訳。これは最終結果だけに置く。
- 3つ星、スコア、ランク。酸素と手数が同じ行動効率を既に表すので、別評価軸はノイズになる。
- `GOOD / PERFECT` のような評価語。探窟記録のregisterを壊す。
- 次の敵の長文説明。層間をチュートリアル画面にしない。

### 4. スキップ

通常層は画面タップで**0.35秒地点から1.45秒地点へ早送り**できる。0秒スキップにはしない。補給が起きた事実だけは350msで必ず見せる。設定の「層間演出を短くする」をオンにした場合は、常にこの短縮版を使う。幕主リザルトは初回だけスキップ不可、二回目以降は長押しで短縮する。深層印の選択自体はスキップできない。

## [E] 深度図の再設計

### 1. 現状の問題

現在のマップは一列の30ノードと開始ボタンで、選択がない。現在地を美しく見せているだけで、プレイ画面へのローディング前室になっている。スクロール距離も長く、情報が増えるほど閲覧コストだけが増す。

地図が面白い作品では、地図は次の四つを同時に決めさせる。

1. 次の戦闘の危険と報酬。
2. 回復・強化・未知イベントのどれを取るか。
3. 今のビルドが得意な敵を通るか、欲しい報酬を優先するか。
4. 数ノード先の合流を見て、短期損と長期利益を比べるか。

本作へは「戦闘／店／焚火」という記号をそのまま移さず、探窟の語彙へ翻訳する。

### 2. 1幕の構造

1幕10深度を、縦に4帯・横に3本の降下路として描く。プレイヤーは通常4面と幕主1面を通る。

| ノード | 意思決定 | 表示 |
|---|---|---|
| **採集域** | 通常課目。知見候補が植物／鉱物寄り | 課目アイコンを公開 |
| **生息域** | 原生種が濃い。突破後は原生種に呼応する知見 | 原生種シルエット＋危険度 |
| **遺構域** | 匣・蔦苔など障害物が多い。未知の知見が出やすい | 障害物の断面記号 |
| **補給孔** | 盤面なしで酸素+5。知見は得ない | 空気流の白い線。新資源は増やさない |
| **未採録域** | 初回は内容不明。踏破後、同じseed族では名称まで開く | 古紙を破いた空白＋疑問符は使わず、輪郭だけ |
| **主の縄張り** | 幕主。深層印を得る | 大きな黒金環印 |

各分岐には、次ノードだけでなく二手先の合流点を見せる。完全な霧では選べず、完全公開では作業になる。既知の原生種は名称まで、未採録種は危険度と食痕だけ、深層印で情報を増減させる。

### 3. 深度の可視化

- 背景一枚絵を縦へ引き伸ばすのではなく、幕ごとに断面図を一枚持つ。現在地の周囲だけ水彩が発色し、未踏部は線画にする。
- 深度1〜30の数字は全ノードへ振らず、5刻みの測深線だけに置く。ノード名が数字に負けないようにする。
- 現在地はキャラクター顔アイコンではなく、小さな真鍮の測鉛と糸で示す。キャラクター絵はプレイ画面と結果画面に集中させる。
- 深くなるほど暗くするのではなく、第一幕は苔緑、第二幕は真鍮灰、第三幕は青紫へ色相を変える。ART v3の「深さは色で描く」を守る。

### 4. 記録の蓄積

採録帖の原生種ページと深度図を連動する。一度観察した原生種は次ランから地図上で名前と兆候が読める。未遭遇では食痕だけ、遭遇で姿、対処成功で対処欄、撃破または無視して踏破で生態欄が埋まる。これは通貨でも永続ステータスでもなく**情報の蓄積**なので、酸素1本の方針を侵さない。

## [F] プレイ画面の情報設計

### 1. 何が「微妙」に見えるのか

添付の通常層・ボス層には、以下の構造問題がある。

- 最上段の酸素 `66`／`107` が巨大な白数字でゲージへ重なり、ラベルも単位もない。深度、メニュー、炎、ゲージ枠と同じ金属装飾の上に載るため、**資源ではなくスコアに見える**。
- 酸素24を満タン基準にする仕様なのに、貯金で66や107まで増える。バーが満タンのまま数字だけ増え、形と数字が別のことを言う。30層化すればさらに破綻する。
- 左右の大札 `裂坑掘り` と `あと2手 掘削` は、敵名・行動・残り手を別々の箱へ分断している。どの敵の兆候か視線を往復しないと分からない。
- 課目チップ `掃討 0/1` と `植物標本 9/50` は、黒地・金枠・大数字が酸素ゲージと同格で、主資源と副目的の優先順位がない。
- 明朝系の和文と、縁取りの強い欧文風数字が同じ行で競合する。`0/1`、`9/50`、`66`、`5/10`の字面がすべて違い、製品UIではなく素材を寄せ集めた印象になる。
- キャラクターのバストが中央で最も大きく、盤面より先に目へ入る。プレイ中の情報ではないのに、課目と盤面を遠ざけている。
- ボス層は盤下辺の赤い長ゲージ、丸い `3`、中央照準が説明なしで並び、上部の兆候札と二重管理になっている。
- 下部の知見アイコンは通常層で5個、ボス層で10個が同じ大きさで横一列に並ぶ。所有物の確認には使えるが、発動中・重要・回数条件の区別がつかない。
- 暗い背景に暗褐色の札を重ね、その上へ白文字を置くため、世界観の暖色セピアより「黒いゲームHUD」が勝っている。

### 2. 新しい読み順

視線を `酸素 → 本層の課目 → 盤面の兆候 → 知見` の順に固定する。

#### 最上段：酸素だけを主役にする

- 深度は左の小メダルに `深度 5`。`5/10`は幕内進行なのか全体なのか曖昧なので使わない。幕表示は小さく `第一幕`。
- 中央はラベル `残酸素`、数値、細いゲージの三段。数値は右寄せで桁が増えても位置を動かさない。
- 酸素は現仕様どおり**上限を設けず**、早解きの貯金を幕越しでも維持する。30層化を理由にクランプすると、急ぐ動機という最上位方針を壊す。
- ゲージは0〜24を「直近の安全域」として描き、24を超えた分を右端の小さな琥珀粒 `予備 +42` として分離する。実値は `残酸素 66` として常に正しく出す。満タンバーに107だけを重ねる現状はやめる。
- 次手で酸素を奪われる場合だけ、ゲージ上に朱の欠け幅と `−3` を予告する。通常の1手消費−1は数字の脈動だけ。

#### 課目：分数をやめ、残りを読む

- 課目は盤面の直上へ、羊皮紙一枚の中に最大二つ並べる。個別の黒いカプセルを二枚置かない。
- 表示は `葉＋茸　植物標本　あと41`、`原生種　あと1`。進捗を知りたい長押し時だけ `9 / 50` を補助表示する。
- 完了時は数字を0にせず、金の採録印へ変えて300msだけ跳ねる。
- 「ターゲット」という見出しは廃止し、初回だけ `本層の課目`。通常時はアイコンと残数だけでよい。

#### 兆候：敵へ戻す

- 原生種名は遭遇時の名前札で一度見せ、プレイ中は敵の長押しで確認する。常設の左大札を削除する。
- 兆候は敵の右上に、形＋残り手だけを出す。`亀裂 2`、`捕食 1`。同種が複数いるときも発生源が一意になる。
- 全体警告は酸素強奪だけ。`肺盗み　1手後 −3` をゲージ直下へ一行出す。盤面妨害を赤くしない。

#### 書体と数字

- 和文見出しは現在の柔らかい明朝を維持する。本文は同ファミリーの中太、10〜12px相当以下ではゴシックへ切り替える。
- 数字は別の**幅が揃ったサンセリフ数字**に統一する。等幅・tabular figures、斜体なし、過剰な黒縁なし。酸素、残数、兆候、深度の全数字を同じ字形にする。
- 数字の階層は酸素 `1.00`、課目残数 `0.56`、兆候 `0.48`、深度 `0.42` の比率。今のようにすべて大数字にしない。
- 白は主数値だけ。ラベルは古紙色、補助値は鈍い真鍮、危険は酸素喪失だけ朱にする。

#### キャラクターと知見列

- バスト高を現状の約70%へ縮め、下半分を盤枠の後ろへ隠す。通常時は彩度を落とし、課目達成・酸素警告・大連鎖のときだけ表情と明度を上げる。
- 知見列は最大6個だけ常時表示し、残りは `＋4` に畳む。直近発火した知見を左へ一時的に浮かせ、回数条件のあるものだけ `1/2` を付ける。
- 採録帖ボタンは文字だけの `野帳` から、閉じた冊子アイコン＋`採録`へ変える。ボス層の10個列でもボタン幅を奪わない。

## [G] 優先順位と工程

### 1. 効き目 ÷ 実装コスト

| 順位 | 施策 | 効き目 | コスト | 判断 |
|---:|---|---:|---:|---|
| 1 | **既存1体を「原生種の完成形」にする縦切り** | 最高 | 低〜中 | 現行burrowerを「崩れ穿ち」へ改名し、専用アート、idle、兆候、採録帖、危険度、初遭遇札まで一組で作る。新ロジック不要 |
| 2 | **HUDの情報階層と数値書体を直す** | 高 | 低 | 大札を削り、酸素・課目・兆候を再配置。新アセットは課目紙面一枚だけでよい |
| 3 | **語彙置換** | 高 | 低 | 強化→知見、接続→呼応、野帳→採録帖等。コードidは変えず表示文字だけを一括変更 |
| 4 | **1.8秒の層間採録帯** | 中〜高 | 低 | 既存の補給・発火集計を使う。全画面リザルトは幕主だけ |
| 5 | **深度図を1幕ぶん分岐化** | 高 | 中 | まず深度1〜10だけ。ノード種5種、三列、四帯。30層を描き切る前に選択が面白いか検証 |
| 6 | **深層印6種のプロトタイプ** | 高 | 中 | 開始3択＋深度10後の3択まで。通常知見と別UIにする |
| 7 | **既存5敵の生態リワーク** | 高 | 中〜高 | 新挙動より先にアート・観察文・idleを完成させる |
| 8 | **第二幕10層** | 中〜高 | 高 | 第一幕の分岐・深層印・所要時間が成立してから量産 |
| 9 | **新機構の敵3種** | 中 | 高 | 苔舐め、鏡綿、鐘脚。既存敵の魅力が立ってから追加 |
| 10 | **第三幕＋特殊ラスボス** | 高 | 最高 | 最後。既存の封鎖・解放を再利用し、専用資源は作らない |

### 2. 実工程

#### Phase 1：魅力の型を作る（1スプリント）

1. 表示語彙を正式表へ置換する。
2. `崩れ穿ち` 一体を完成納品単位で作る。
3. 同じ層5でHUDを新階層へ変更する。
4. 層クリア1.8秒帯に、酸素・手数・最多知見を出す。
5. 5人のプレイテストで「敵の名前／次の行動／対処」を説明できるか確認する。

合格条件は、説明文を読まない初見3人中2人が、二回目の兆候までに「枠内を一つ消せば止まる」と言えること。美麗さの投票だけで判断しない。

#### Phase 2：選択の型を作る（1〜2スプリント）

1. 第一幕の深度図だけを三列分岐にする。
2. 開始深層印3種、幕主後3種を実装する。
3. 通常4面＋幕主1面の1幕所要時間を計測する。
4. runsimを分岐対応し、各経路の到達酸素と選択率を測る。

第一幕が8〜12分、幕主到達率55〜75%、三経路の選択率がいずれも15%以上なら第二幕へ進む。

#### Phase 3：量産（以後）

- 第一幕の型を使って第二幕、第三幕を順に作る。
- 一幕ごとに新機構は**課目1、原生種行動1、幕主規則1**まで。三つ以上同時に足さない。
- 新アートは原生種の完成納品単位で発注し、盤上アイコンだけ先行させない。
- 30層完成後に特殊ラスボスを作る。途中で仮ラスボスを量産しない。

### 3. 後回し／やらない

- **30面の直列化**：やらない。所要時間と完成ビルドの反復がモバイルに合わない。
- **敵と知見を同時に倍増**：やらない。相互作用のQA組合せが四倍になり、各要素の演出が薄くなる。
- **祝福を通常知見の高レア版にする**：やらない。数値が大きいだけなら別システムの意味がない。
- **3つ星・スコア・コインの復活**：やらない。酸素という唯一の評価軸を濁らせる。
- **図鑑用の説明文を先に大量生産**：やらない。盤面行動とシルエットが決まった個体だけを書く。
- **参照作に似た生物シルエット、衣装、小物**：絶対にやらない。観察記録・危険度・生態の構造だけを使う。

### 4. 最初の一手

**深度5の裂坑掘りを、完成形の原生種「崩れ穿ち」へ一本だけ作り直す。**

理由は、現行エンジンの予告2×2・中断・移動をそのまま使え、ロジック追加なしで、命名、原生種アート、idle、兆候UI、採録帖、危険度、層間追記を一度に検証できるからである。ここで魅力の型が成立しないまま30層へ進むと、魅力のない敵と説明札を三倍に増やすだけになる。逆にこの一体が成立すれば、盤殻・糸釣蛾・肺盗みは同じ生産工程で量産できる。

## 最終判断

本作の独自性は「深界風の絵」ではなく、**盤面上の現象を観察し、知見として採り、次の探窟で未知が既知へ変わること**に置く。酸素が一手の価値を決め、原生種がいつもの最適手を一時的に禁じ、知見がその制約を壊し、深度図がどの危険を引き受けるかを選ばせる。この四者がつながったとき、語彙・敵・マップ・リザルトは別々の追加機能ではなく、一つの探窟体験になる。

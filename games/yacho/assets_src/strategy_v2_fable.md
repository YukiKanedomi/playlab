つまり盤上には「**障害物に目玉を描き足したもの**」と「**丸**」が並んでいます。生態を書いても行動を足しても、ここを直さない限り魅力は出ません。**だから最初の一手は「1体の縦切り」ではなく「既存6種の絵の一括発注」です。**1体だけ直しても、盤面には目玉つき障害物が5体残り、同じ指摘が必ず返ってきます。

**さらに安い一手が1つ見つかりました。** `e_swarm_angry` / `e_swarm_dead` / `e_swarm_spore` の3相は `pieces.ts` に**登録済みなのに一度も参照されていません**（`makeEnemyBlock` は「怒る局面が無いので通常顔で固定」と書いて通常相のみ使用）。**新素材ゼロで「生きている感」が出るか**を今日にでも判定できます。

### 3.2 全種に一括で効く3つの仕掛け

**(1) 危険度は3段。数字の梯子にしない**
5段＋「消灯＝帰還者なし、以下は伝聞」という格付けは、単位こそ独自でも**構造が参照作品の署名**です。3段に落とし、**採集人の野外図鑑が実際に書く語**にします。

| 段 | 語 | 意味 |
|---|---|---|
| 1 | **採れる** | まとめて採ってよい。数だけ数えよ |
| 2 | **気をつけろ** | 対処に二、三手。無視すれば採集が遠のく |
| 3 | **採るな** | 油が直接減るか、盤の前提が壊れる。動く前に方針を決めよ |

**(2) 常設は記号1つだけ。文章は絶対に常駐させない**
3提案が同じ画面の同じ帯を取り合っていたので、ここで調停します。

- **盤面に常設**＝敵タイル上のバッジのみ（`あと2` ＋小アイコン ＋ **縁色1点**で危険度。無彩／朱／金）。**語も文章も出さない**
- **文章**＝タップで野帳シート。初回遭遇の1回だけ自動で開き、**どこをタップしても即閉じる**
- 左右に浮いている遭遇チップは**廃止**（5体いても1枚に集約されるので、どいつが動くか読めない）

**(3) 提示は「記載」と「扱い」の2段。記録は育つ**
現行の `ENEMY_INFO` は全種が「妨害の内容」「倒し方」の2行で、**何を食べ何に食われるかが1文もありません**。これを2段に置き換えます。

> **記載**　傘の縁から太い管が三本、空気の匂いを探して揺れている。悪気はないのだと思う。面套の継ぎ目から漏れた息と、岩の隙間に溜まった空気を、区別できないだけだ。前を歩いていた者の灯が、三度またたいて消えた。<br>――第七次 三ノ坑／記録者：（探窟家名を流用）
>
> **扱い**　採るな。三手ごとに油を三つ持っていく。傘を大きく破れば（四つ以上そろえ）一つ吸い返せる。

### 3.5 見た目の規律（AD判断）

**識別記号を「目」から「灯」へ移します。**唯一資源が油＝灯である以上、生きもの側にも灯の記号を持たせるのが世界と一致します（現行の失敗＝障害物に目を1つ描き足す、の反省が「目を識別記号にする」では同じ失敗の言い換えになります）。

**AD判断を3つ確定します。**

1. **検品基準は「36pxに縮小して種が判別できること」**（従来案の64pxは実寸より甘い）。各生物を**「輪郭1つ＋異物1つ＋色1つ」の3要素に削る**。既存の `e_swarm` が成功しているのは丸1つ＋目2つ＋淡い斑点しかないからです。螺子蟲＝平たい甲＋**太い螺子1本**（複眼7粒は黒い横線1本へ）、苔喰らい＝平たい体＋**白い花1輪**、灯消し＝薄い袋＋**太い管3本**。細部は野帳シート用の拡大図に回す。

## 4. 30層と祝福（要望5・6・7）

### 4.1 「30層」は要望をそのまま実装するのが正しいか（オーナー決定事項C）

**結論：30層ぶんのコンテンツは全部作る。ただし「1ランで30層潜る」形にはしない。**

**(a) 1ランの実時間の試算**

`BoardView.ts` の juice 定数から、演出の実時間は確定できます。

| 内訳 | 値 |
|---|---:|
| 成立スワップ `T.swap` | 150ms |
| 消滅ポップ `T.pop` | 200ms |
| 落下 `T.fall` | 380ms |
| reconcile 待ち | 200ms |
| 追加連鎖（実測 平均1.65〜2.14連鎖 → +0.85段 × `chainBeatFor` 平均440ms） | 約375ms |
| **演出だけの小計** | **約1,305ms** |
| 思考時間（**未計測・推定**） | 1.5〜3.5秒 |
| **1手 合計** | **約2.8〜4.8秒（中央 3.3秒）** |

| | 手数 | 盤面 | ＋ドラフト/演出/画面 | **合計** |
|---|---:|---:|---:|---:|
| 現行10層 | 91.6手 | 5.0分 | 2.5分 | **約7.5分** |
| 30層 通し | 約285手 | 15.7分 | 7.3分 | **約23分（幅18〜30分）** |

**(b) 23分はモバイルとして妥当か → 妥当でない。**長さそのものより**「安全な離脱点がない23分」**であることが問題です。Slay the Spire（45〜90分）や Balatro（30〜60分）が成立しているのは長さではなく**いつでも中断して即座に再開できる**からで、本作に中断セーブはありません。層28で油が尽きたら20分が消える——モバイルではこれは事故ではなく日常です（電話・通知・電車の到着）。

**(c) さらに重い問題：作ったものを誰も見ない。**現行クリア率39.2%を幕ごとの通過率とすると、**幕2到達39%／幕3踏破6%／終幕4%**。最も設計コストが高い影追い・底肉・銘3枚を、実質誰も見ません。「まだ見たことのないものがある期待」は、**到達不能と確信された瞬間に不満へ反転します。**

**(d) 要望の本質は「ボリューム」＝"まだ見たことのないものがある"の総量であって、"1回の座り時間を3倍"ではない**——他の要望がそれを示しています。要望4は「あっさり。**ただしテンポと相談**」＝長さでなく密度。要望7は「パターンを増やす。**全ての要素に魅力を**」＝密度。要望8は進行の見え方。

**(e) 決定：中継地点（ベースキャンプ）方式。**

> **30層は1本の縦坑として作る。ただし、初めて第一帯を抜けたら「層11から潜る」入口が恒久解禁される。**以後は入口を選んで潜る＝**1ラン＝1帯＝10層＝約8分**が既定。通しで30層降りる走り方は「上」として残す。

これで4つ同時に解けます。

| 問題 | 解け方 |
|---|---|
| 複利で誰も見ない | 第一帯を抜けた人の**100%が第二帯を遊べる** |
| セッション23分 | 既定は8分。腰を据えたときだけ通しの23分 |
| 酸素の較正 | **帯ごとに独立に較正できる**（現行の `OXYGEN_START=38` / 補給+8 は10層専用の較正値で、幕跨ぎの検証は一度もされていません。通しは帯切替の一括補給1変数だけで調整） |
| 中断で20分が消える | 帯単位なら最大8分。通しは帯の切れ目が安全な離脱点になる |

そして**これがそのままメタ進行になります**（3本の批判すべてが「メタ進行が無いまま30層を作るのが最大の欠陥」と指摘した点への回答）。解禁されるのは入口だけでなく、**銘のプール1枚／野帳の頁1枚／開始の油+1**も同時に。「負けても野帳は回収される」という §2.5 のフィクションが、そのまま受け皿になります。

**(f) 追加の条件：目標の型を先に増やすこと。**層が3倍になるのに、現行の目標型は4種（収集／蔦苔／陶片／殲滅）のまま据え置きの提案でした。**プレイヤーの動詞「どのマスを、なぜ消すか」を決めているのは敵より目標です。**敵14種を詳細に設計して目標型を1行で済ませたのは、優先順位が逆です。第二帯に進む条件として**新目標型を2つ先に実装し、うち1つを既存10層に試験導入して手触りを確認する**こと。

- **運び出し**：指定の駒を盤の縁まで運ぶ（`光胞子の搬送` は PLAN_LOOP §1.5 で「浮上と落下の相互作用が読みにくい」として第2弾送りになった経緯があるので、**浮上でなく"押していく"形に作り直す**）
- **護り**：盤上の1つ（灯／苗）を規定手数だけ守る。生きものはそれを狙う

### 4.2 3帯の性格（数値を上げるだけの幕を作らない）

参照作品を分解すると、共通しているのは**「操作は最後まで同じ。要求される思考の種類が変わる」**ことです。Slay the Spire は敵の攻撃の"質"（単発→多段・デバフ→両方）、Hades は空間の性質（狭い部屋→床が害を出す→少数の強敵）、Balatro はボスブラインドによる**一時的な規則の書き換え**。数値を上げているだけの幕は1つもありません。

| | **第一帯 苔の坑道** | **第二帯 機械遺構** | **第三帯 燐光の底** |
|---|---|---|---|
| 一言 | 集める帯 | 運ぶ帯 | 癖と戦う帯 |
| 目標 | 収集（現行のまま） | **運び出し・護り**（新型） | 既知の型＋**癖**が常時かかる |
| 要求される技術 | どこを消すかの**選択** | 落下と分断を読む**空間計画** | 制約の穴に**ビルドを通す運用** |
| 生きものの役割 | 妨害（封鎖・捕食印） | **盤面の形を変える** | **常時ルールを書き換える** |
| 環境 | 素直 | 非対称・穴あき・分断 | 毎層1つの**癖** |
| 標本の扱い | **組む**（毎層ドラフト） | **磨く**（重ねがけが常時混ざる） | **使う**＋最後に壊れた1枚 |

**癖（旧「呪い」）の例**：濁り（毎手1マスが別の色へ）／軋み（4つ以上でしか通らない）／静寂（標本の発動が1手2回まで）／痩せ（この層の補給が半分）／石化（毎手1マスに甲殻）／引き潮（2手ごとに油-1）。予告つき（層に入る前に見える）。⚠️ ROGUE2 §3 の禁則「ビルドが無価値になる敵は作らない」は癖にも適用します。**「植物系の標本が全部無効」のような完全メタは作らない。**上の6つはどれも**やり方を変えれば通る**制約です。

### 4.3 「第三帯で標本が増えない」は撤回する

当初案は「第三帯はドラフト3回のみ。もう増えないこと自体が緊張の源」でしたが、**これは遠慮しすぎです。**runsim 実測で `発火/手` は層1の0.60 → 層10の11.84（約20倍）、`破壊/手` は7.88 → 15.56 と伸び続けており、**この伸びこそが本作の気持ちよさの実体**です。ROGUE2 §5 の目指す体験（終盤＝植物が勝手に増え、そのたび鉱石が爆発し、ギアまで動く）とも逆行します。

**修正：第三帯のドラフトは「数を絞る」のはそのまま、「質を上げる」へ転換。**3枚を**第三帯限定プールの壊れた標本**（第一帯の10倍の効果／各1回きり）にします。20分積んだビルドの最後に、想定外の壊れ方を1つ足せることが第三帯の報酬になります。

> ⚠️ **ただし発火予算の破綻が先に来ます。**`board.ts` は1解決あたりフック発火200回で打ち切り、その到達を「ご褒美フラグ」として扱っています。層を3倍・ドラフトを増やし・重ねがけを入れると、層20以降は常時200上限に張り付きます。**ご褒美フラグが常態化して意味を失うだけでなく、打ち切られた標本は「持っているのに発動しない」＝ビルドの因果が壊れます。**30層設計に入る前に、runsim を30層へ延ばして（`runsim.ts` の `floor <= 10` 3箇所を `FLOORS.length` へ）**発火/手・200上限到達率・破壊/手を層30まで出す**こと。1手の実時間も固定値ではなく破壊数の関数として見積もり直すこと（「深層は手数が減るから総時間は伸びない」という前提は、この曲線を見ていません）。

### 4.4 銘（祝福）

**(a) 強化と祝福の切り分けは「発火点の名前空間」で行う。**

「規則を書き換えるか否か」で切ると**プレイヤーには見分けがつきません**（現行の `共振破砕`＝爆発範囲を十字→3×3、`磁気採掘`＝爆発に巻き込まれたギアが消えない、は既に規則の書き換えです）。

| 軸 | 標本 | 銘 |
|---|---|---|
| **発火点** | **盤面の中**：`match` / `destroy` / `gearTrigger` / `sporeTouch` | **盤面の外**：`floorStart` / `floorClear` / `oxygenSpend` / `draftOpen` / `enemySpawn` / `lastBreath` |
| スケール | 1手の中の出来事を増やす（局所・高頻度） | 踏査の会計と規則を変える（大域・低頻度） |
| 見え方 | **盤面上で光る** | **HUDの数字と規則表示が変わる** |

**発火点が1つも重ならないことが本体です。**「標本は駒に効き、銘は踏査に効く」——説明なしで理解できます。**盤面に触る銘はゼロ。ここは例外を1枚も作りません**（当初案は12枚中3枚が盤面効果で、自分が「唯一の防波堤」と呼んだ規則を自分で破っていました）。

**(b) 実装は「フックに `on` を5つ足すだけ」ではありません。**現行の Hook は `match / destroy / sporeTouch / gearTrigger / turnEnd` の5種で、`turnEnd` は一度も配線されていません。しかも**20種中9種はフックを経由せず** `board.ts` 内の `run.upgrades.includes(X_ID)` の真偽で分岐しています。銘の発火点は `board.ts` の `spendMove` / `checkFloorClear`、`enemies.ts` の `ENEMY_HP` / `ENEMY_PERIOD`（どちらもモジュールレベルの Record）、`main.ts` のドラフトパネル、`run-over` 直前と**4ファイル5層に散ります**。土台工事を先に3つ：`run.ts` に銘の配列／`ENEMY_HP` `ENEMY_PERIOD` をインスタンス値化（`createEnemy` で確定）／`checkFloorClear` の補給量を `run` 由来にする。**初弾はドラフト側と `floorClear` 側だけに限定**するのが実装順として正しい。

**(c) 銘の一覧（8枚から開始）**

★＝代償を含む＝**契約プール**（入口を選ぶときに1枚。**ただし第一帯を初めて抜けた後に解禁**）。無印＝**ご褒美プール**（極相種を仕留めた後に3択で1枚）。

| # | 名 | 何が変わるか | 発火点 |
|---:|---|---|---|
| 1 | ★**大きな肺** | 層クリアの補給が +8 → +12。ただし開始の油 -10 | `floorClear` / 初期値 |
| 2 | ★**標本狂い** | 層の採集数 +25%。ただし層クリアの補給 +50% | `floorStart` / `floorClear` |
| 3 | ★**静けさの誓い** | 生きものがいない層は油の消費が半分（切り上げ）。2体以上いる層は消費+1 | `oxygenSpend` |
| 4 | ★**前ぶれ** | 生きものの行動周期 +1（予兆が1手早く読める）。ただし体力 +2 | `enemySpawn` |
| 5 | ★**帰路を捨てる** | 中継地点へ戻れなくなる（＝通しで降りるしかない）代わり、**極相種ごとに銘を2つ選べる** | 初期フラグ |
| 6 | **早鐘** | 各層の最初の1手は油を消費しない | `oxygenSpend` |
| 7 | **拾い直し** | ドラフトで選ばなかった1枚が、次のドラフトに必ず戻ってくる | `draftOpen` |
| 8 | **忘れ形見** | 踏査中に一度だけ、油0になった瞬間に油+10で戻る | `lastBreath` |

> **`draftOpen` 枠は1枚だけ**にしました。当初案は12枚中5枚が「ドラフトの経済をいじる」1アイデアの変奏で、プレイヤーには「**どのドラフト改造がいちばん強いか**」という算数に見えます。掲げた役割（踏査の性格を宣言する）を果たしません。判定基準は**「これを取ると、同じ10層でも走り方が変わるか」**。
>
> **#5 帰路を捨てる**が世界観の核です。「もう帰らない」を**プレイヤーが自分で宣言できる**。宣言すると強くなる。当初案は効果を「全ダメージ+1」＝盤面効果かつ ROGUE2 原則3（数値強化より挙動変化）への正面違反にしていたので、**会計側（銘が倍もらえる）へ書き直しました**。

**(d) 代償あり／なしを混ぜる理由。**全部に代償を付けると銘が標本の亜種に戻ります（トレードオフのある部品＝Balatro のジョーカー＝まさに標本の役割）。全部を純粋恩恵にすると選択が「一番強いのはどれ」という算数になり、2周目以降に固定化します。混ぜると**「今回は素直に強くなるか、性格を変えるか」**という質の違う問いになります。**入口＝契約（★のみ）／極相種＝ご褒美（無印のみ）**とプールを分けるだけで、この役割分担は自動的に成立します。

**(e) 初見に契約を選ばせない。**★プールは**第一帯を初めて抜けた後の解禁要素**にします。契約が何を変えるかを知らない初見に、最初の操作として代償つきの選択を強いるのは明確な悪手です（StS も Hades もラン冒頭に選択を置いていません）。第一帯に入れるのは**標本＋採集＋油＋生きもの4種だけ**。危険度・癖・銘・重ねがけは全部第二帯以降。

> ### **プールを 20種 → 36種（+16種。帯ごとに+8ずつ解禁）**

**深い帯でだけ出る標本がある**こと自体が潜る理由になります。増設の方向：既存の因果グラフ（`RESOURCES` 7語彙）を**閉じる**もの／**2手先に効く**もの（現行は全て即時発火なので、時間軸の追加は既存の高速な因果に**リズム**を与えます）／第三帯限定の**壊れた1枚**（各1回きり）。

**重ねがけ（同じ標本をもう1枚取ると効果が2回発動）は常時ONにします。**第二帯以降のドラフトに「所持済み1枚」を常に混ぜる。パッケージ中いちばん面白いアイデア（Balatro の快感そのもの）を「枯渇対策」の脚注に埋め、しかも銘でゲートするのは扱いが小さすぎます。**第二帯の看板機能**として前に出し、2枚目・3枚目でカードの見た目と文言が変わる（「同じ標本が二度書かれている」）。層間リザルトの主役表彰（§5.2）と組み合わせると、ビルドが物語になる導線が1本通ります。

> ⚠️ **重ねがけは「実装コスト小」ではありません。**`board.ts:87` は `UPGRADES.filter(u => run.upgrades.includes(u.id)).flatMap(...)` で、同じIDを2つ入れても**フックは1本しか登録されません**（重複が構造的に潰れる）。さらに20種中9種（蔓ロケット／胞子弾／磁気採掘／共振破砕／予熱／模倣の粘菌／自律機構／機械庭園／遺物の根）は `includes` の真偽で分岐しており、何枚重ねても効果は増えません。`applyStarters` はラン1回に固定、`run.progress` は id キーの単一エントリなので2枚目が1枚目の進捗を上書きします。**採るなら**：(a) `board.ts:87` を所持配列ベースの登録に変える (b) ID特例9種は**重ねがけ非対象**としてドラフトから除外 (c) `startersApplied` をカウンタ、`run.progress` を id+index キーへ——の3点を仕様に書き込むこと。

### 4.6 終幕『帰路』（特殊ラスボス）

> **極相種（影追い）を倒しても踏査は終わらない。地上へ戻る道が残っている。**

| 要素 | 仕様 | なぜ |
|---|---|---|
| **補給がない** | 上りは層クリア補給ゼロ。**倒した時点の残油だけで地上まで走る** | 「降りるときに使いすぎたぶん、帰れない」という因果。理由は物理（油の湧く場所から離れる） |
| **生きものは出ない** | 代わりに**越えてきた極相種3体の影**が要所で足を止める | **既存のボス実装を再利用＝安い**。「自分が越えてきたものが、帰り道では障害になる」 |
| **底肉** | §3.3。体力を持たず、油を攻撃に変換する層 | 30層かけて「油＝残り手数」と教えたルールの、最後の裏返し |
| **失敗しても損しない** | 途中で油が尽きたら「坑に還った」。**30層踏破の記録・解禁は確定済み** | ここが設計上いちばん重要。上りを「失敗すると全部消える追加試練」にすると賢いプレイヤーは挑まなくなり、終幕が死にコンテンツ化する。「勝ちは確定、その上に真エンドがある」なら全員が挑む |

**重力反転（駒が上へ落ち、補充が下から来る）は第2弾送り。**理由はコストではありません（ビュー側の `fall` は from/to 座標駆動で上向きでもそのまま動き、コア側も `applyVerticalGravity` / `applyDiagonalSlide` / `refill` の3関数に方向を通すだけで `resolveCascades` 本体は無改造）。**本当の障害は光胞子です。**`afterMove` は光胞子を「1手ごとに1マス上へ浮上させ、上端で回収して目標を進める」独自ルールを持ち、`applyVerticalGravity` も「胞子は落ちない」で特別扱いしています。重力を上向きにすると胞子は重力と同方向になり、**この機構と胞子目標が丸ごと意味を失います。**反転をやるなら、その層で胞子目標と胞子を生む標本をどう扱うかを先に決める必要があります。

### 5.1 プレイ画面

**症状と実体**

| 症状 | 実体 |
|---|---|

3. **大きい数は「野帳の方眼」で図形化。**羊皮紙の札に薄いセピアの方眼を8マス罫線で引き、4個ごとに1マスへ**朱の斜線（タリー）**。数字は右に小さく併記。⚠️ モックの「星3レール」の意匠は**転用しないでください**——ローグ・ピボットで廃した星評価の記号なので、廃した軸が視覚的に復活します。
4. **油は円メダリオンへ。**未登録の `moves_medallion.png` / `hp_medallion.png` をそのまま転用（新素材ゼロ）。**画面で最大の数字**にし、バーを残すなら **1手＝1目盛りの油量計**（5手ごとに太目盛り）で必ず1メモリ減るようにする。単位は付けず `のこり 38`。
   - ⚠️ **3桁は情報設計では解けません。**補給に上限を付けるか開始値のレンジを変えるか——中継地点方式なら帯ごとに独立較正できるので、そこで2桁に収める。

> ⚠️ 当初案の「遭遇帯26%を廃止して盤面を58%へ」は**採用しません。**モック `user_v3_3` ① を実測すると、上部の情景バンドが約46%／盤が約40%／ブースター帯13%で、**モックは現行実装より情景帯が広く盤が狭い**。面積予算という論の土台が事実誤認でした。しかも「HUDと盤の間に探窟家バスト」は ART.md v3 の柱で、廃止は正典変更にあたります。

本当の差は面積ではなく、**モックのバンドが帯テーマの背景画で埋まった「場所」なのに対し、実装は空白の上にバストと文字チップが浮いていること**です。したがって処方は「畳む」ではなく**「背景を敷いてキャラを立たせる」**。既存の `bg_forest` / `bg_machine` / `bg_crystal` をそのバンドに敷き、HUD をその上に浮かせる＝モック①の構成へ戻す。盤は現行46%のまま触らない。**空白が消えれば「スカスカ」は面積を動かさずに解決し**、しかも「深さを色で体感させる」が地図でなくプレイ画面で毎手発揮されます。廃すのは帯ではなく**帯の中を浮遊する左右の敵チップだけ**（予兆は敵タイル上へ移す）。

**書体とラベル方式（AD判断）**

ART.md は行15で「主要ラベルは画像に焼き込み」、行125で「文言は全てコード描画。画像内文字は使わない」と**自己矛盾しています**。**AD判断として「文言＝コード描画、地＝画像」に一本化し、行15 を改訂**します（行125が正）。語彙が20箇所以上動く最中に焼き込みへ倒すのは最悪のタイミングです。

ただし「素材とコード文字が混在して浮いて見える」は本物の指摘なので、**原因を方式でなく描画品質で潰します**：見出し文言に (a) 古紙色 `#E8D9B0` の1px内側ハイライト＋濃セピアの本体色、(b) 2〜3%の回転と字間 +0.04em、(c) 不透明度92% を共通で当てて「紙に刷られた」感を再現する。数字は `letterSpacing +0.06em` ＋ `fontWeight 700` ＋ stroke で太らせ、等幅扱いにして桁変動でガタつかせない。結果画面の `さいだい連鎖` `1手さいだい破壊` のひらがな開きは統一がなく子供っぽいので `最大連鎖` `一手の最大破壊` へ。

**ついでに2件**：ドックは層10で標本10個が約44pxに潰れて読めない → **5個＋「+5」**に丸め、全体は引き出しで。右下ボタンは中身が「特殊駒＋敵＋用語＋標本」の**混合ドロワー**で、**どんな名前を付けても合わないのは中身が混ざっているから**です（名称の前に中身を分けるか、明確に「調べもの」の一箇所に統一するかを決める）。

### 5.2 層間リザルト（要望4）

ローグライトの層直後の演出は3種に分解できます。**A. 報酬の提示**（2〜10秒・操作するので長くてよい）／**B. 決算の提示**（1.5〜4秒・1画面3〜5行・見るだけなのでスキップ必須）／**C. 状態の更新**（0.8〜1.5秒）。現状は **C（リボン1.4秒＋補給fx）→ A（ドラフト）** で、**B が完全に欠落**しています。「あっさり」の正体はこれです。

**見せるのは3つだけ。**

1. **油の収支を1行の式で** — `−11 使って ＋8 補給 → のこり 35`。唯一の資源なので決算の主役はこれ以外にありえず、**「回復量」と「掛かった手数」の要望2つを1行で同時に満たします**
2. **標本が働いた回数** — `発動 14回（最大 5回／手）`。`upgradeFireCount` と `maxFiresInOneMove` は既に集計済みで、層ごとにリセットして出すだけ
3. **今層でいちばん働いた標本1つ** — アイコン＋名前＋回数

**見せてはいけない**：スコア（本作にスコアはなく、無理に作ると星3という別軸を背負う）／撃破数・破壊駒数の羅列（**3行を超えたら負け**）／ハイスコア比較（ランごとに条件が違うので無意味）。

**位置はドラフトの前。**ドラフトは「次に何を伸ばすか」の決定で、**その判断材料が層間リザルト**です。材料を後に出すのは順番が逆ですし、ドラフトの後だと**選んだ直後の余韻を上書き**します。現行のリボン1.4秒の枠に収まる＝新しい間を作らずに済みます。

```
0.00s  リボン「第○層 踏破」スケールイン（既存 320ms）
0.30s  リボン直下に細い羊皮紙の札がせり出す（180ms）
0.40s  1行目：油の式が左から順に灯る（200msずつ・カウントアップはしない）
         「−11」朱 → 「＋8」金（既存の補給fxと同時） → 「のこり 35」
1.00s  2行目：今層の主役の標本アイコンが1つポンと出る＋「発動 14」
1.40s  札とリボンが同時に退場（280ms）
1.60s  ドラフトへ
```

- **スキップ必須。**画面のどこをタップしても全tweenを完了状態へ飛ばす。**1ランで9回、100ランで900回見る演出**なので、1.6秒でもスキップ不可なら憎まれます
- 音はファンファーレ1つのみ。数字ごとに鳴らすと3連打で安っぽくなる
- **主役方式**が効くのは、同じ標本が3層連続で主役になれば「これがこのランの背骨だ」と分かるから。ビルドが物語になります。`maxFiresInOneMove` が自己ベストを更新した層だけ「新記録 7連」の金の押印を足す
- **3行目に極小のスパークライン**（過去層の補給前残油）。追加尺0秒（既存tweenに乗る）。runsim の合否基準(c1)で油は単調減少するよう較正されているのに、**その傾向がプレイヤーに一度も見えていません**。「降りるほど細る」を語れるのはここだけです
- **遭難時も同じ書式で1枚**：`油 0。第7層で遭難` ＋ その層で最も働いた標本。成功と失敗を同じ書式で記録すると、失敗が「記録の一部」に見えます

### 5.3 マップ（要望8）

**意味をなしていない理由は描画ではなく参照先です。**`buildMap()` が描いているのは**旧30レベル制キャンペーンの地図**で、ノードは旧 `LEVELS` 配列、星は旧 `save.unlocked`、タップは撤去済み（コメント「装飾としてのみ残す」）。実質「開始ボタンつきの壁紙」です。

**ところが描画そのものは既に完成しています。**蛇行パス・ノード金/銀・現在地リング・アバターピン・ドラッグスクロールが実装済みで、素材（`map_node` / `map_node_gold` / `map_stararc` / `map_avatar`）も全て登録済み。

> ### 処方：**参照先を差し替えるだけ。**`save.unlocked` → `run.floor`、`LEVELS.length` → `FLOORS.length`、`save.stars` → 層ごとの目標種別。深度バッジのタップで「**いま降りている縦断面**」（通った層＝金／現在地＝リング／未踏＝暗）が出る。**新規素材ゼロ、分岐ゼロ。**

**分岐マップは作りません。**参照作品の地図が与えている判断は4つ（リスクとリターンの交換／資源の配分計画／**経路のコミット＝戻れない**／ビルドの方向づけ）ですが、当初案は「必ず次の層で合流」＝**コミットがゼロ**でした。合流型は1回ごとの選択が独立なので結局安く、得られるのは2択の目標プレビューだけ。39個の `FloorDef` という実装コストに見合いません。**その予算を縦断面の可視化に全振りする**ほうが、マップ・層間リザルト・深さの実感を1つの部品で同時に解けて、コストは1/5以下です。

汎用ノード種別（店／休憩／短い戦闘）も本作では機能しません：**通貨がない**（店を作るなら新サブシステム丸ごと）／**体力がなく油は自動補給**（休憩＝補給の数字が大きいだけ＝大小比較に還元）／1層は常に8.7〜11.6手で**ノードのコストが一定**。

**3つのモードを混ぜない。**拠点（最深到達と「もぐる」だけ。**星もスコアも出さない**）／入口の選択（中継地点。ドラフトと同じパネル様式）／経路の閲覧（縦断面。読み物・操作しない）。⚠️ **全画面の縦長地図をスクロールさせて次を探させるのはモバイルで最悪の操作**です。

**絵づくり**：`map_bg`（縦穴の断面）は素材として活かす。**10層ごとに地層の色が変わる**（苔 → 機械 → 燐光。テーマ背景は既に3枚ある）。各極相種の層の手前に**大きな石の門**を描き、「10層ごとにボス」を数字ではなく地形で伝える。**30層の底に光る一点**を最初から見せておく——**未到達でも見える目的地**は、縦穴という舞台が持つ最大の資産です。

## 7. やらない方がよいこと（明示）

| やらないこと | 理由 |

| **1ランを30層の連続プレイにする** | 23分・離脱点なし・幕3到達6%。作ったものを誰も見ない |
| **分岐マップ（枝つき FloorDef ＋ 分岐パネル）** | コミットがゼロで選択が安い。39個の FloorDef のコストに見合わない。縦断面の可視化に全振りするほうが1/5のコストで同じ以上に効く |

| **螺子蟲の「大きく消すと損」** | SPEC_OXYGEN §0.2 決定#7（全敵共通の `heavy: boolean` 1行ルール）の巻き戻し。かつ爆発ビルドの持ち主に理不尽 |

# 『そろえて、しるす。』設計書（DESIGN.md）

> ルールと数値の正典。演出の数値根拠は RESEARCH.md §5、意匠は ART.md。2026-08-11 起草。

## 1. コア仕様

- 盤面 8×8（レベルにより欠けあり）。色数：Lv1-10=4色、Lv11-=5色。
- スワップ式。縦横3+で消滅。**入力は原則ロックしない**（アニメ中もセル単位で受付。解決中のセルのみ操作不可）。
- 自動シャッフルなし。リフィルは**詰み防止制御**（有効手が0にならないよう補充色を選ぶ。シード付き乱数）。
- 特殊駒（生成形→効果）：
  - **銛** 4連一列 → 1行/1列全消し（向きあり）
  - **羽虫** 2×2 → 残り目標へ飛び1マス破壊＋離陸時に隣接消し。目標消滅時は転向
  - **火壺** L/T字5 → 5×5爆破
  - **星珠** 5連一列 → 盤面最多色を全消し
  - 合成は RM 10通り全対応（RESEARCH §1 の表の通り）。タップ発動あり。
- 障害物：苔石(Lv1・2層/隣接or特殊駒)・蔦苔(Lv4・下敷き/上でマッチ)・匣(Lv11/壊すと陶片が目標化)・巣灯(Lv21/隣接ヒットで光胞子排出→**胞子は1手ごと1マス浮上、上端到達で回収**。規定数で自動閉鎖)。
- ブースター：事前配置=銛1本置いて開始（Lv6解禁）／ゲーム中=遺物鎚（1マス破壊・手数消費なし、コイン払い。Lv9解禁）。

## 2. 経済・メタ

- **スコア＋3つ星**（2026-08-12 AD v2 で採用）：消去1駒=10点×連鎖倍率、特殊駒発動=+50点。星は閾値制（★1=クリア、★2/★3=レベル定義の閾値）。クリア画面はモック③準拠。
- 星の消費：タスク=★1×6件/エリアは「獲得星の合計」から支払う方式に変更（3つ星化に伴う）。
- ライフ制はモックにハート表示があるが**不採用のまま**（Web無料配信の合意を維持）。キャラ選択スキル・アイテム・図鑑・会話イベントは v2 候補（BACKLOG）。
- コイン：クリア報酬 +60〜80（基準68）／ボーナスレベル 300-700 相当は「発掘ボーナス」1回で代替検討／追加5手=900／遺物鎚=200。
- ライフ・課金・広告なし。

## 3. レベル構成（30本・3層）

難易度は RM 実測に合わせる：通常=平均1.2回試行、Hard=1.6、Super Hard=2.5。5レベル周期の鋸歯。手数 30-38(序盤)→25-30(中盤)→23-27(終盤)。

| 層 | Lv | 新要素 | 山場 |
|---|---|---|---|
| 第1層 淵の口（白金の光） | 1-10 | Lv1苔石 / Lv4蔦苔 / Lv6事前銛 / Lv9遺物鎚 | Lv5, Lv10(Hard) |
| 第2層 逆さ森（ティール） | 11-20 | Lv11匣（単体導入→混合） | Lv15, Lv20(Hard) |
| 第3層 灯の底（発光紺） | 21-30 | Lv21巣灯（単体導入→混合） | Lv25(Hard), **Lv29-30=絶界行**（ブースター不可・報酬増・Super Hard） |

- 新要素の導入レベルは**その要素単体のみ**で構成（RM実測の学習設計）。
- 各層でパレット・背景・BGMトーンが深く沈む（深さは色で描く）。

## 4. 画面・演出

- 勝利7段階（RESEARCH §5 実測準拠、計約12-15秒）：『大発見！』バナー(約3s)→ヘッダーがReward表示へ→残手数ドレイン(30-60ms/手・彗星→特殊駒変換)→自動起爆ラッシュ(5-6s・コイン噴水)→★獲得→記録完了スタンプ画面→（次ロード時）野帳Tipsカード。
- 敗北：相棒獣の表情＋「あと少し」提示→追加5手提案(900コイン)→やめても罰なし。
- juice実測値：消滅ポップ170-230ms／苔石破壊270-330ms（消滅より重く）／落下330-430ms＋着地バウンス／連鎖ビート600-800ms／連鎖SEピッチ半音ずつ上昇。
- メタ：縦断面図マップを下へスクロール。野営地タスクで野帳に描き込みが増える（完成絵のレイヤー分解方式）。

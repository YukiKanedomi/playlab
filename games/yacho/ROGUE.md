## 0. MVPスライス（最初に作る範囲＝核心仮説の検証）

**仮説**：「自分で選んだ強化同士が連鎖して、1スワイプから盤面が壊れていく瞬間」は気持ちいい。

- 1ラン = **10層**（目標10〜15分）。10層目にボス1体
- 強化ドラフト = 層クリアごとに**3択**、プール**20種**
- 敵 = 簡易3種＋ボス1体（盤面干渉型）
- 環境 = 2種（菌糸層・結晶洞）を中層以降に挿入
- 呪い・エンドレス・中断セーブ・記録の共有機能は**MVP外**（ビルド命名と基本記録だけ入れる）
- 判断基準：自分で3ラン遊んで「もう1ラン」と思えるか

## 1. 設計原則（企画書 §17 の実装翻訳）

1. **数値より挙動**：強化は盤面の因果（生成・変換・起動）を足す。ダメージ%は原則禁止
2. **位置依存**：効果は必ず「触れた」「隣接」「通過した」で発動する。どこをスワイプするかが最後まで意味を持つ（自動化の主体性喪失への防波堤）
3. **操作は増やさない**：入力はスワップ（＋特殊駒タップ）のみ
4. **終盤は意図的に壊す**：エンジンは決定的（seeded）だが上限は緩く。長連鎖は倍速/スキップ演出で受ける
5. **毎ラン違う判断**：ドラフトはシナジー2系統＋外れ1の比率で抽選

## 2. 駒の系統マッピング（現アセット流用）

| 系統 | 駒（色スロット） | アセット | 系統特性 |
|---|---|---|---|
| 植物 | 葉(n1)・キノコ(n4) | p1_leaf / p4_mushroom | 増殖・胞子・連鎖 |
| 鉱物 | 青結晶(n2) | p2_crystal | 爆発・高威力・採掘 |
| ギア | 歯車(n0を差し替え) | **新規生成 p0_gear**（金系色を維持） | 起動・自動発動・生成 |
| 遺物 | 紫花(n3)→**遺物駒に差し替え** | **新規生成 p3_relic**（紫系維持。ref_v3_parts の遺物/巻物意匠） | コピー・増幅・変換 |

- **トークン（駒ではない盤面オブジェクト）**：胞子=s_spore流用（設置型・隣接に反応）／爆発鉱石=結晶の変異状態（発光tint）
- 特殊駒（レンチ銛/コンパス甲虫/歯車爆弾/虹彩ランタン）は現行仕様のまま。強化による亜種化（蔓ロケット等）はMVP外
- 障害物資産は敵の身体に転用（苔石=岩殻、封印匣=ボス部位 等）

## 3. エンジン拡張：フックシステム（board.ts）

強化＝**イベントフックの束**。resolveCascades の各フェーズで発火し、追加アクションをイベント列に積む（決定的・ビューは既存タイムラインで追従）。

```ts
interface RunState {
  upgrades: UpgradeId[]
  gearCharge: number       // ギア起動カウンタ類
  playerHp: number         // 探窟隊HP（MVP: 20）
  floor: number
  records: RunRecords      // 最大連鎖/最大破壊数/発動効果数…
  // バランス再設計で追加（可視化契約。ビューはこの2つを読む）
  progress: Record<string, { cur: number; max: number }> // 回数条件で発動する強化の進捗（自律機構/機械庭園/遺物共鳴）
}

type Hook =
  | { on: 'match'; pieceKind?: PlantEtc; minSize?: number; act: (g: MatchGroup, ctx: Ctx) => void }
  | { on: 'destroy'; act: (cell: XY, cause: Cause, ctx: Ctx) => void }
  | { on: 'sporeTouch'; act: (spore: XY, neighbor: XY, ctx: Ctx) => void }
  | { on: 'gearTrigger'; act: (at: XY, count: number, ctx: Ctx) => void }
  | { on: 'turnEnd'; act: (ctx: Ctx) => void }

// Ctx が提供する決定的アクション（すべて既存 BoardEvent に変換される）
spawnToken(at, 'spore') / transform(at, to) / explode(at, r) / chargeGear(at)
damageEnemy(at|nearest, n) / spawnPiece(at, color) / convertSpecial(...)
```

- ギア「起動」の定義：ギア駒がマッチ消滅 or 爆発に巻き込まれる＝1起動
- 胞子：設置後、隣接セルで駒が消えると「触れた」扱い→フック発火→胞子消費
- 爆発鉱石：破壊時に十字1マス爆発（爆発は destroy 連鎖を生む）
- ループ暴走対策：1解決内のフック発火は上限200（超えたら打ち切り＋記録に「臨界」フラグ＝ご褒美扱い）

## 4. MVP強化20種（ドラフトプール）

> **バランス再設計（発動条件の緩和）**：`minSize:4`→原則3、`minSize:5`→4、ギア3回起動系（#10自律機構/#19機械庭園）→2回起動に緩和。
> 「位置依存」の原則は崩さない。効果量が寂しかった#7採掘慣れ（1→2ダメージ）・#20遺物の根（胞子1→2個）は1段強化。
> **ラン開始時に強化を1つ配布**（`STARTER_UPGRADE_IDS`＝20種全体からrngで1つ。連鎖の起点を最初から持たせる）。
> **進捗の可視化**：回数条件系（#10/#19/#13）は `RunState.progress` に `{cur, max}` を持ち、ビューが「1/2」等を表示できる。
> **スターター効果（第4波で訂正）**：ROGUE2.md §1 原則2のスターターは、本体効果の発動条件（胞子/爆発鉱石/特殊駒等）が
> 盤面に無いと機能しない**条件付き強化8種のみ**に付ける（#3毒胞子/#5根食い鉱/#6共振破砕/#9磁気採掘/#13遺物共鳴/
> #14模倣の粘菌/#17蔓ロケット/#18胞子弾）。他12種は本体効果だけで単体成立するためスターター無し
> （プレイテスト指摘「全部に付けるのはやり過ぎ」「メインは本体効果、スターターはおまけ」を受けた訂正。詳細はROGUE2.md §4）。

### 植物（4）
1. **胞子繁殖** 植物を3つ以上消すと、胞子が2つ生まれる
2. **菌糸の目覚め** 植物を消すと、となりの空きマスに植物が生える
3. **毒胞子** 胞子が敵のとなりで消えると、その敵に3ダメージ（スターター：胞子を2つ置く）
4. **深呼吸** キノコを消すと、盤面のどれか1つが植物に変わる

### 鉱物（4）
5. **根食い鉱** 胞子が鉱物にふれると、その鉱物が爆発鉱石になる（スターター：胞子を2つ置く）
6. **共振破砕** 爆発鉱石の爆発が十字から3×3に広がる（スターター：爆発鉱石を2つ作る）
7. **採掘慣れ** 鉱物マッチが敵の甲殻と岩に追加2ダメージ
8. **結晶の芽** 鉱物を4つ以上消すと、爆発鉱石が1つ降ってくる

### ギア（4）
9. **磁気採掘** 爆発にギアが巻きこまれると消えずに充填され、次のギアマッチが2倍になる（スターター：爆発鉱石とギアを置く）
10. **自律機構** ギアが2回起動するたび、特殊駒が1つ生まれる
11. **過回転** ギアマッチが連鎖を1段のばす
12. **予熱** 層のはじめにギアが3つ増える

### 遺物（4）
13. **遺物共鳴** ギア起動でとなりの遺物が光り、次の遺物マッチが2倍になる（スターター：最初の1回を2倍にしておく）
14. **模倣の粘菌** 遺物を3つ以上消すと、直前の強化効果がもう一度おきる（スターター：遺物を2つ置く）
15. **変換炉** 遺物マッチのとき、となりの駒1つが盤面で最も多い色に変わる
16. **賭博師の壺** 遺物マッチのたび、半々で特殊駒か邪魔ピースが生まれる

### 異種シナジー（4）
17. **蔓ロケット** 植物4つ消しのレンチ銛が、通った道を植物に変える（スターター：レンチ銛を1つ作る）
18. **胞子弾** 歯車爆弾のあとに胞子が1つ残る（スターター：歯車爆弾を1つ作る）
19. **機械庭園** ギアが2回起動するたび、植物が2つ生まれる（§4-10と重複取得で循環完成）
20. **遺物の根** 遺物マッチのたび、胞子が2つ生まれる

> 抽選規則：所持済み強化とシナジーするものを2枠（系統一致 or 因果が繋がる）、無関係1枠。同一強化の重複は無し（MVP）。

## 5. 敵とターン（MVP）

- **ターン**：プレイヤーの1スワップ=1ターン。連鎖中は敵は動かない。ターン終了時に敵行動
- **プレイヤーHP**：探窟隊HP20。敵の攻撃で減少、0でラン終了。植物系の回復強化は将来枠
- **敵の実装**：盤面に居座る「HPブロック」（kokeishi の拡張。隣接マッチ・爆発・特殊駒でダメージ）
- **バランス再設計（プレイテスト反省）**：旧仕様は妨害のみでプレイヤーHPをほぼ削らず「危険ゼロ」だった。
  各敵は**妨害と攻撃を交互に**行う（周期は2ターンのまま。1回目=妨害→2回目=攻撃→…と交互）。攻撃ターンは
  プレイヤーHPを直接削る。ボスは元々攻撃のみ（3ターン周期の全体攻撃）なので変更なし
- **公開API（ビュー契約）**：`enemyIntent(e: EnemyInstance): { kind: 'attack' | 'disrupt'; damage?: number; turns: number }`
  （`turns`=次の行動までの残りターン数。内部の `turnsUntilAction` はそのまま残るが、ビューはこちらを読む）

| 敵 | HP | 妨害行動 | 攻撃ダメージ | 資産 |
|---|---|---|---|---|
| 岩殻獣 | 8 | 鉱物1つに甲殻付与（1回余計に消す必要） | 3 | o_stone 流用+目 |
| 胞子獣 | 6 | 植物1つを毒胞子化（消すとHP-1） | 2 | o_subi 流用+目 |
| 穴潜み | 10 | 空きセル1つを2ターン封鎖して移動 | 2 | 新規（穴） |
| **ボス：巨大深層生物** | 30 | （妨害なし）下2行を身体で塞ぐ。5ダメ与えるごとに1行後退→復帰を繰り返す | 3ターンごとに全体攻撃(HP-3) | 新規1枚（横長の身体） |

- 攻撃手段：敵に**隣接するマッチ**=マッチ数ぶんダメージ、爆発=3、特殊駒=各定義。「攻撃コマンド」は存在しない（企画書 §12）
  ※これは「プレイヤーが敵を攻撃する」手段の話。敵からプレイヤーへの攻撃（上記の交互ローテ）とは別軸
- イベント：敵の攻撃ターンで `{t:'enemy-attack'; id:number; damage:number}` が発火する（既存の `boss-slam` はボス専用のまま維持）

## 6. 層構成（MVP 10層）

| 層 | 内容 |
|---|---|
| 1-2 | 素の3マッチ＋岩殻獣1（チュートリアル圧力） |
| 3-4 | 敵2体。3層クリアで最初のドラフトが効き始める |
| 5 | **環境：菌糸層**（3ターンごとに植物1つ自然増殖） |
| 6-7 | 敵2〜3体。特殊駒の使い所 |
| 8 | **環境：結晶洞**（3ターンごとに鉱物1つが成長=隣に鉱物生成） |
| 9 | 敵3体・混成 |
| 10 | **ボス層**。撃破でクリア→記録画面 |

- 層目標はMVPでは「敵殲滅」に統一（採掘/救助/逃走は第2弾）
- 手数制は廃止。プレッシャーは敵行動とHPが担う

## 7. ラン記録とビルド命名（MVP）

- 記録：到達深度 / 最大連鎖 / 1手最大破壊数 / 発動効果総数 / ボス撃破
- **ビルド自動命名**：取得強化の系統比率と代表強化から生成
  `[修飾=代表強化] + [主系統名詞] + [装置/庭園/炉/工場]` 例：胞子繁殖+機械庭園多め →「暴走菌糸機関庭園」
- クリア画面は現行クリアパネルを流用し、星→記録リストに差し替え

## 8. 画面フロー（MVP）

```
タイトル（ラン開始）→ 層1 … 層クリア → ドラフト3択（羊皮紙カード3枚）
 → 層2 … → 層10ボス → 記録画面（命名+記録+もう一度）
```
- マップ画面は「現在深度の表示」に転用（縦断面図をそのまま流用、ノード=層）
- ドラフトUI：クリアパネル資産＋強化カード（枠のみ生成、本文はコード描画→好評ならv2で焼き込み）
